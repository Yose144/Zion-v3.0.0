## 1. Nasazeno do produkce

### L3 Hiranyagarbha — živá AI vrstva (3.3)

Veřejný chat `POST /api/ai-chat` na `app.zionterranova.com` je **LIVE** a odpovídá reálně přes grounded RAG pipeline:

```
prohlížeč → nginx (rate-limit 6 r/min/IP, 20 r/min global)
          → Next.js /api/ai-chat
          → L3 ai-native API  (Edge 127.0.0.1:8001, BM25 RAG nad 49 kurátorovanými dokumenty, 670 chunků)
          → reverzní SSH tunel (Edge 127.0.0.1:8002)
          → llama.cpp na operátorském PC (GTX 1070 Ti, Qwen3-1.7B-Q8_0, ~25 tok/s)
```

- **LLM běží lokálně**, ne na Edge (Edge nemá GPU a jen ~1.5 GB volné RAM). GPU je sdílené s minerem — VRAM ~7.0/8 GB, hashrate beze změny (~16.6 MH/s).
- Tunel je user-unit `zion-hiran-tunnel` → Edge uživatel `hirantunnel` (`nologin`, key restricted `permitlisten="127.0.0.1:8002"`); Edge `zion-v31-ai-native.service` (MemoryMax=512M, reálně ~15 MB).
- Webová route akceptuje jen nedegradovanou odpověď (`source==null`, ne echo-prefix), jinak 503. LM Studio/Ollama fallbacky jen přes `HIRAN_DEV_FALLBACKS=1`.
- Dřívější nginx 503 gate zrušen (backup `/root/zion-edge-download.conf.bak-*-aichat-ungate`), rate-limit zóny zůstaly.
- **Kvalita:** 1.7B model dělá faktické chyby i s RAG — L3 je operátorský nástroj, ne zdroj pravdy.
