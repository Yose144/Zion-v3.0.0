# V3.1 Architecture Reorganization Plan

> **Goal:** Rework the `V3/` tree into a clean, layer-correct, duplication-free layout for **Mainnet Alpha (3.1.0)**. Move WARP and ZionDex under `L2`, merge AuxPow natively into the miner, and dedicate `L3` exclusively to AI/ML, orchestration, automation, NCL and future PoC.
>
> **Target version:** 3.1.0  
> **Status:** 🔵 Planning  
> **Related:** [`MAINNET_ALPHA_PLAN.md`](./MAINNET_ALPHA_PLAN.md), [`3.1.0.md`](./3.1.0.md), [`V3/README.md`](./V3/README.md), [`V3/ROADMAP.md`](./V3/ROADMAP.md), [`V3/Cargo.toml`](./V3/Cargo.toml)

---

## 1. Why we need this

Current `V3/` grew organically and carries several structural problems:

| Problem | Where | Impact |
|---------|-------|--------|
| **WARP in L3** | `V3/L3/warp/` | WARP is a bridge protocol; it belongs next to `L2/bridge` so native L2 logic is unified. |
| **ZionDex outside V3** | `ZionDex/` root | Cross-chain DEX should live under `V3/L2/` like the other financial primitives. |
| **AuxPow duplicated** | `AuXpow/` root + `V3/L1/miner/` + `V3/L1/cosmic-harmony/` | External coin hashrates, stratum clients and share forwarders are split across crates, causing drift. |
| **L4/L5/L6** | `V3/L4/oasis/`, `V3/L5/free-world/`, `V3/L6/issobella/` | These are AI/agent modules, not distinct infrastructure layers. They should fold into a single AI layer. |
| **Legacy root trees** | `L1/`, `L2/`, `L3/` (repo root) | Confuse agents and new contributors; should be archived. |
| **Philosophy/research** | `docs/TerraNova/`, `docs/Zohar/`, `PoC-lab/`, `HiranV2.x/` | Not runtime code; should move to docs/philosophy or a separate research repo. |

### Design principles

1. **Layer = business domain**, not marketing name.
   - `L1` = chain, consensus, mining.
   - `L2` = on-chain/off-chain finance and interoperability.
   - `L3` = AI, orchestration, automation, future research.
2. **One source of truth per concept.** `ExternalCoin`, `CoinProfile`, revenue sources and stratum protocol live in exactly one crate.
3. **Miner owns mining.** AuxPoW is not an external satellite crate; it is part of the miner runtime.
4. **Bridge & WARP are siblings.** Both move value in/out of L1; both run under L2.
5. **No L4/L5/L6.** All AI-related code is under `L3/`.

### 3.3 Merge AuxPow into the miner

Current split:
- `AuXpow/` (repo root) — external stratum clients, share forwarders, GPU kernels for AuxPoW.
- `V3/L1/miner/` — main ZION miner, GPU dispatch, stratum.
- `V3/L1/cosmic-harmony/` — `ExternalCoin` enum, profit router, revenue sources.

Target:
- **Eliminate `AuXpow/` root crate.** Move its code into `V3/L1/miner/src/auxpow/` and `V3/L1/miner/src/gpu/`.
- **`V3/L1/cosmic-harmony` stays the canonical source for `ExternalCoin`, `CoinProfile`, revenue sources.** No duplication.
- **Miner directly imports external-coin hashing and stratum logic** from the new `auxpow` module.
- **Pool keeps `AuxPowBridge`** in `V3/L1/pool/`, but uses the *same* stratum types as the miner (shared in `V3/L1/types` or `cosmic-harmony`).

| Action | Details |
|--------|---------|
| Audit `AuXpow/` vs `V3/L1/miner/` | List duplicate types (`ExternalCoin`, `ExternalStreamJob`, share types, stratum messages). |
| Decide canonical location | Keep `ExternalCoin`/`CoinProfile` in `cosmic-harmony`. Move hashing kernels and stratum client to `miner/src/auxpow/`. |
| Merge GPU backends | Unify OpenCL/CUDA/Metal dispatch between miner and AuxPoW kernels. Avoid two `gpu_backend.rs`. |
| Update feature flags | `native-hashers`, `native-randomx`, `native-verushash`, `native-ghostrider` become miner features. |
| Delete `AuXpow/` root | After build passes; archive first if needed. |

**Build criterion:** `cargo check -p zion-miner --features full,native-hashers` passes with no `AuXpow` path dependency.

## 5. Execution phases

### Phase 0 — Freeze & inventory

1. Create this plan (done).
2. Tag `pre-v3.1-reorg` on `main`.
3. Inventory every import/path reference to the moving crates.
4. Decide final crate names.
5. Open a long-running `v3.1-reorg` branch.

### Phase 1 — AuxPow → miner

1. Move `AuXpow/src/` logic into `V3/L1/miner/src/auxpow/`.
2. Move `AuXpow/csrc/` OpenCL kernels into `V3/L1/miner/csrc/` or `V3/L1/cosmic-harmony/csrc/` depending on ownership.
3. Merge `ExternalCoin`/`CoinProfile`/`RevenueSource` so only `cosmic-harmony` owns them.
4. Update `V3/L1/miner/Cargo.toml` dependencies and features.
5. Build & test `zion-miner`.
6. Archive/delete `AuXpow/`.

### Phase 2 — WARP L3 → L2

1. `git mv V3/L3/warp V3/L2/warp`.
2. Update `V3/Cargo.toml`.
3. Update all internal path references and `edge-deploy/` configs.
4. Build & test `zion-warp`.

### Phase 3 — ZionDex root → L2

1. `git mv ZionDex V3/L2/ziondex`.
2. Convert standalone workspace into V3 workspace members.
3. Update website build / API imports.
4. Build & test router contracts + Rust router.

### Phase 4 — Flatten AI layers

1. `git mv V3/L4/oasis V3/L3/ai/oasis` (and L5/L6 similarly).
2. Create new crates: `L3/orchestrator`, `L3/automation`, `L3/poc` (can be scaffolds).
3. Update `V3/Cargo.toml`.
4. Build & test.

### Phase 5 — Repo-wide cleanup

1. Archive root legacy trees (`L1/`, `L2/`, `L3/`) per [`MAINNET_ALPHA_PLAN.md`](./MAINNET_ALPHA_PLAN.md).
2. Move `docs/TerraNova/`, `docs/Zohar/` to `docs/philosophy/`.
3. Move `PoC-lab/`, `HiranV2.x/` to `archive/research/` or separate repo.
4. Update root README/ROADMAP/AGENTS/StatusV3.

### Phase 6 — Verification

1. `cargo check` whole V3 workspace.
2. `cargo test` whole V3 workspace.
3. Run E2E smoke: node + pool + miner + bridge + warp + ziondex.
4. Update public subtree (`public/V3/`) and verify diff.
5. Tag `v3.1.0-alpha.1`.

## 6. Go / No-Go for starting the reorg

**GO:**
- 3.0.8 "Full Stack Stable" is achieved (or at least the mining/bridge/warp parts are stable enough to branch from).
- A `v3.1-reorg` branch exists and CI runs on it.
- Every moving crate has a clear owner.

**NO-GO:**
- Active hotfixes are still landing daily in `main` — would cause merge hell.
- 3.0.7 All Green is not finished — fix mining first, then reorganize.

## 7. Risks & mitigation

| Risk | Mitigation |
|------|------------|
| Moving WARP breaks 500+ tests | Move with `git mv`, run tests after each phase, fix imports incrementally. |
| AuxPow merge creates huge diff | Do it in a dedicated sub-branch, one external-coin family at a time. |
| ZionDex contracts use different Foundry config | Keep `foundry.toml` inside `V3/L2/ziondex/contracts/`; add workspace-level CI step. |
| Public subtree desync | Run `git subtree push --dry-run` before final merge; update `public/V3/` paths if needed. |
| Documentation becomes stale | Update docs in the same PR as the code move; do not merge moves without doc updates. |
| Build times explode | Keep `profile` settings; consider `cargo metadata` validation in CI. |
