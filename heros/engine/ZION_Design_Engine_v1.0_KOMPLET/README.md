# ZION Design Engine v1.0

Schválený styl je **B · ZION**, prostřední panel v každé srovnávací sadě.

| Složka | Obsah |
|---|---|
| 01_NOVE_ILUSTRACE | Tři samostatné nové scény ve schváleném stylu B |
| 02_PREDCHOZI_HERO | Sedm dosavadních samostatných obrazů od App po Hiran |
| 03_STUDIE_A_B_C | Pět triptychů, celkem 15 vizuálních variant |
| 04_REFERENCE | Starší ZION Manga Style Bible |

Soubor ZION_DESIGN_ENGINE_v1.0.md je výchozí dokument pro další zadávání. Obsahuje pravidla pro výtvarný styl, webové plochy, Nirvanu, OASIS a avatary. Jednotlivé obrázky jsou ilustrace a kandidáti pro web, se schvalováním identity, výřezu a použitelnosti podle konkrétního umístění. Tato sada zahrnuje všechny ilustrace a triptychy z této série.
