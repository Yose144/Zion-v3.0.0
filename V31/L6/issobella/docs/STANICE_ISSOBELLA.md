## 1. Původ jména

**Issobella** = **ISS** (International Space Station) + osobní jméno.

Symbolizuje kontinuitu lidské přítomnosti ve vesmíru a propojení technologie s vědomím. V moderním ZION ekosystému je Issobela **Strážkyní Lidskosti** — správce největší části humanitárního a vědeckého fondu a patronka kosmického výzkumu.

## 2. Mise stanice

### 2.1 Vědecká observatoř

- Astronomický výzkum bez atmosférické distorze.
- Monitoring klimatu Země — satelitní data podporují L5 Free World.
- Komunikační relay pro decentralizované P2P sítě.
- Kvantové experimenty v mikrogravitaci.

### 2.2 Výzkumné centrum

- Testování kvantového motoru ve vesmíru.
- Materiálový výzkum v mikrogravitaci.
- Biologické experimenty — kosmické farmy, růst rostlin.
- Deep-space komunikační technologie — laserové linky, kvantová kryptografie.

### 2.3 Symbol a inspirace

- Stálá přítomnost decentralizované komunity na orbitě.
- Vzdělávací live-streamy z vesmíru pro komunitu i školy.
- Důkaz, že community-funded vesmírný program je možný.
- Most mezi pozemským ekosystémem a kosmickou budoucností lidstva.

### 2.4 ZION Space Network

- Satelitní mesh síť propojená se ZION P2P uzly.
- Redundantní uzly v orbitě — nezávislost na pozemní infrastruktuře.
- Radiation-hardened ZION node (FPGA) pro autonomní consensus.
- ISL (Inter-Satellite Links) pro komunikaci mezi satelity.

## 6. Technické požadavky stanice

### Hardware

| Komponent | Specifikace |
|-----------|-------------|
| Platforma | Modulární orbitální stanice LEO |
| Výška oběžné dráhy | 400–550 km |
| Napájení | Solární panely + iontové baterie |
| Radiation hardening | FPGA-based ZION node |
| Komunikace | ISL + laserové downlinky |
| Životní prostředí | Mikrogravitace + umělá gravitace (rotující torus), ochrana proti radiaci |

### Umělá gravitace

- Rotující **habitation torus** pro dlouhodobý pobyt posádky.
- Cílová úroveň **0,38 g** (Mars) pro běžný život; rehabilitační zóna **1,0 g**.
- Nízké RPM (< 2,5) pro minimalizaci Coriolisových efektů a motion sickness.
- Podrobný fyzikální a designový návrh: [`L6data/Umela_Gravitace.md`](../../../L6data/Umela_Gravitace.md).

### Kvantový motor / kvantová energetika

- Testovací modul (**Quantum Motor Bay**) propojený s L5 Free World výzkumnými laboratořemi.
- Více výzkumných cest: iontový / plazmový / Hall / spekulativní kvantově-koherentní systémy.
- Bezpečnostní brány (G0–G5) před instalací na stanici.
- Podrobný výzkumný plán: [`L6data/Kvantovy_Motor.md`](../../../L6data/Kvantovy_Motor.md).

### ZION Space Node

- Radiation-hardened FPGA spouštějící zjednodušený ZION consensus.
- High-latency P2P — uzly na orbitě komunikují s 50–100 ms zpožděním.
- Autonomní validace — stanice může fungovat i při výpadku pozemní linky.
- Mesh relay — satelity přeposílají transakce mezi sebou.

### Observatoř

- Optické dalekohledy (viditelné světlo, infračervené).
- Spektrometry pro analýzu atmosfér exoplanet.
- Zemské snímkování pro klimatický monitoring.
- Radioastronomie bez pozemského rádiového smogu.
