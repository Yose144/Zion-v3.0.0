### Pool FULL V3 Feature Parity ✅ COMPLETE

**Nové moduly (7):**
- `auxpow_runtime.rs` (448 lines) — AuxPoW bridge runtime: spawn tokio task per coin, connect to upstream pools, fetch jobs, forward shares. Exponential backoff (5s→600s). Per-coin wallet override.
- `tls.rs` (175 lines) — TLS support (tokio-rustls 0.26 + rustls 0.23 + rustls-pemfile 2). Non-fatal. ExtraPortConfig for difficulty-stratified extra ports.
- `share_relay.rs` (120 lines) — Fire-and-forget share relay for Edge→Core pool forwarding. 3s write timeout.
- `profit_switcher.rs` (210 lines) — Pool-side profit switcher with hysteresis. Uses ProfitRouter for estimates.
- `routing.rs` (370 lines) — RoutingStats (per-group/source submit tracking), resolve_session_group, extract_group_hint, session_group_name, group_index, source_index, ALL_REVENUE_SOURCES. 11 unit testů.
- `deferred_payout.rs` (570 lines) — DeferredPayout queue s retry processorem, check_tx_on_chain, get_chain_height, execute_fee_payout, fee_payout_recipients, spawn_deferred_payout_processor, spawn_payout_confirmation_sweep. 5 unit testů.
- `ncl_gateway.rs` (703 lines, ported from V3) — NCL AI compute gateway client, pricing, task dispatcher, heartbeat config.

**Pool Runtime Wiring (2026-08-04):**
- **Notifier** (Telegram/SMTP/OASIS/webhook) zapojen do StratumServer + PayoutSweeper

  - `notify_payout_failed()` při chybě payout sweep

## 8. CLI Command Reference

### Wallet
```bash
zion wallet create [--force]              # Generate Ed25519 keypair → ~/.zion/wallet.json
zion wallet load                          # Load wallet from file
zion wallet send <to> <amount> [--dry-run] [--memo TEXT] [--rpc URL] [--fee N]
```

### Pool
```bash
zion pool start                           # Start pool systemd service
zion pool stop                            # Stop pool systemd service
zion pool status                          # Show pool systemd service status
zion pool stats                           # Show pool statistics (JSON)
zion pool payouts                         # Show latest PPLNS payouts
zion pool shares                          # Show pool share statistics
```

### Miner
```bash
zion miner start [--reward-address ADDR] [--pool-url URL] [--node-rpc-url URL] [--auxpow-pool URL] [--worker NAME] [--no-zion] [--no-gpu] [--no-cpu]
zion miner stop                           # Stop miner systemd service
zion miner status                         # Show miner systemd service status
```

### Node
```bash
zion node start [--db-path PATH] [--rpc ADDR] [--p2p ADDR] [--human ADDR] [--issobella ADDR]
zion node stop                            # Stop node via systemctl
zion node status                          # Show systemd status for node
zion node restart                         # Restart node via systemctl
```

### Service
```bash
zion service start|stop|restart|status [node|pool|miner|multichain|dao|all]
zion service logs <service> [--lines N]   # journalctl log viewer
```

### Other
