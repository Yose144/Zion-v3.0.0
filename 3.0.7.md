## Co je 3.0.7

3.0.7 je **stabilizační a E2E verifikční release** po 3.0.6 "Triple Parallel". Zatímco 3.0.6 přinesl architekturu a kernelovou podporu pro 24 externích coinů, 3.0.7 se zaměřuje na to, aby **každý aktivní stream skutečně produkoval ověřené accepted shares** a aby celý mining stack byl připravený pro širší veřejné použití.

### Hlavní cíle (aktualizováno 2026-07-19 po ověření)

1. **Trinity All Green** — ZION Deeksha + externí GPU + externí CPU streamy mají potvrzené accepted shares bez kritických regresí.
2. ~~**Dokončit E2E pro externí coiny**~~ — ✅ RVN, DCR, ERG, EPIC hotové. ✅ ETC hash verify — CPU reference `ethash` 0.4 crate vs CUDA kernel `ETHASH_CPU_GPU_MATCH` (~121 MH/s, epoch 0). Zbývá: FLUX/EVR/MEWC/CLORE/ETC live upstream share.
3. **Stabilizovat VRSC** — 3 hotfixe commitnuty, potřebuje 1h soak test pro potvrzení <5% stale.

## Aktuální známe blockery (z [`StatusV3.md`](./StatusV3.md) a archivních reportů)

- **GPU algoritmy — CUDA kernel verification sweep (2026-07-27)**
  - ✅ ETC `ethash` CPU/GPU match ověřen (`ETHASH_CPU_GPU_MATCH`, ~117.6 MH/s na GTX 1070 Ti, epoch 0). Zbývá live upstream share.
  - ✅ CUDA benchmark PASS pro 10/11 testovaných algoritmů: `kheavyhash`, `blake3_alph`, `blake3_dcr`, `autolykos`, `zelhash`, `ethash`, `kawpow`, `progpow`, `evrprogpow`, `meowpow`.
  - ❌ `verushash` CUDA init FAIL — vyžaduje build s `native-verushash`.
  - ⚠️ CPU reference stále chybí pro `kawpow`, `progpow`/`evrprogpow`/`meowpow` a `autolykos`.
- **RVN KawPow** — `Invalid nonce` na NiceHash; potřeba ověřit extranonce1 fix.
- **DCR Blake3** — benchmark PASS, CPU reference pro share submit stále neověřen end-to-end.
- **ERG Autolykos** — `unknown` rejection; CUDA kernel běží, ale pravá Autolykos v2 implementace chybí.
- **FLUX / CLORE / IRON / KLS / DNX** — pool reachability nebo auth problémy z Edge datacenteru (u FLUX deprecated).
- **XMR RandomX** — datacenter IP blocking; všechny pure-RandomX pooly unreachable nebo auto-switchují na KawPow. Stále řešit `stale job_id`.
- **Vega / SMOS** — EPIC ProgPow GPU hang; BMI2 SIGILL na starších CPU (Pentium G4560).
- **Pearl (PRL)** — miner-side GPU thread není implementován; pool-side infra ready.
