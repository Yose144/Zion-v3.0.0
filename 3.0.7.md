## Co je 3.0.7

3.0.7 je **stabilizační a E2E verifikční release** po 3.0.6 "Triple Parallel". Zatímco 3.0.6 přinesl architekturu a kernelovou podporu pro 24 externích coinů, 3.0.7 se zaměřuje na to, aby **každý aktivní stream skutečně produkoval ověřené accepted shares** a aby celý mining stack byl připravený pro širší veřejné použití.

### Hlavní cíle (aktualizováno 2026-07-19 po ověření)

1. **Trinity All Green** — ZION Deeksha + externí GPU + externí CPU streamy mají potvrzené accepted shares bez kritických regresí.
2. ~~**Dokončit E2E pro externí coiny**~~ — ✅ RVN, DCR, ERG, EPIC hotové. Zbývá: ETC (hash verify), FLUX/EVR/MEWC/CLORE (live E2E test).
3. **Stabilizovat VRSC** — 3 hotfixe commitnuty, potřebuje 1h soak test pro potvrzení <5% stale.
4. ~~**Rozhodnout o Pearl (PRL)**~~ — ✅ **Oficiálně deferred do 3.1.0** (2026-07-19). PRL jobs zůstávají ignorované v mineru, Pearl zůstává pool-only infra.
5. ~~**Dokončit placeholder kernely**~~ — ✅ VTC, ZCL, RTM, QTC, NEXA všechny E2E PASS.
6. ~~**Explorer V4**~~ — ✅ Routes live at `/explorer`. Zbývá: ověřit detail pages, fix dashboard health.
7. **Public repo sync** — po dosažení All Green zkusyncovat `public/` subtree.

## Aktuální známe blockery (z [`StatusV3.md`](./StatusV3.md) a archivních reportů)

- **ETC Ethash** — `Invalid share` i po fixu mix_hash / DAG epoch; pravděpodobně endianness / seed_hash / FNV bug.
- **RVN KawPow** — `Invalid nonce` na NiceHash; potřeba ověřit extranonce1 fix.
- **DCR Blake3** — `below_target`; ověřit kernel proti CPU referenci.
- **ERG Autolykos** — `unknown` rejection; ověřit GPU hash vs CPU.
- **FLUX / CLORE / IRON / KLS / DNX** — pool reachability nebo auth problémy z Edge datacenteru.
- **XMR RandomX** — datacenter IP blocking; všechny pure-RandomX pooly unreachable nebo auto-switchují na KawPow.
- **Vega / SMOS** — EPIC ProgPow GPU hang; BMI2 SIGILL na starších CPU (Pentium G4560).
- **Pearl (PRL)** — miner-side GPU thread není implementován; pool-side infra ready.
