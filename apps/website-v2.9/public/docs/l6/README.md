## Co je L6 / Issobella?

L6 je **vesmírná vrstva** ZION ekosystému:

- Modulární orbitální stanice LEO (400–550 km) do roku 2040+.
- Financována 5 % z každého block reward do L6 fondu.
- Decentralizované rozhodování o misích a výzkumu přes ZION DAO.
- Cílem je otevřená věda, umělá gravitace, kvantový výzkum a Overview Effect pro lidstvo.
