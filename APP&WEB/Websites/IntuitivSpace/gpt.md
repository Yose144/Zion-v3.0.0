výhod me základní koncepty na téma : Intuitivní prostor 
Téma „intuitivní prostor“ je široké a můžeš ho uchopit různě – architektonicky, UX/designově, psychologicky nebo i duchovně. Níže máš přehled základních konceptů, které se často opakují napříč obory:
1. Přirozená orientace (Wayfinding)
Prostor by měl „vést sám“ bez potřeby přemýšlení.
Jasné linie pohybu
Viditelné cíle (světlo, otevřený prostor)
Minimum rozhodovacích bodů
👉 Člověk intuitivně ví, kam jít.
2. Hierarchie prostoru
Prostor má čitelnou strukturu:
hlavní → vedlejší → servisní
veřejné → poloveřejné → soukromé
👉 Mozek rychle chápe „co je důležité“.
3. Vizualní vodítka (Affordance)
Objekty naznačují, jak se mají používat:
dveře „zvou k otevření“
cesta „táhne dopředu“
schody „vedou nahoru“
👉 Design komunikuje bez slov.
4. Tok (Flow)
Plynulý pohyb bez překážek:
žádné zbytečné bariéry
přirozené přechody mezi zónami
👉 Prostor „teče“, nebrzdí.
5. Minimalismus a redukce šumu
méně objektů = lepší orientace
odstranění chaosu
👉 Intuice funguje lépe v jednoduchosti.
6. Světlo jako navigace
světlo přitahuje pozornost
tmavé = méně důležité
přirozené světlo vede směr
👉 Lidi instinktivně následují světlo.
7. Materiály a textura
změna povrchu = změna funkce
teplé vs. studené materiály
👉 Tělo „cítí“ prostor, nejen vidí.
8. Měřítko a proporce
lidské měřítko = komfort
velké prostory = význam / síla
malé prostory = intimita
👉 Emoční reakce bez vědomého uvažování.
9. Opakovatelnost a rytmus
opakující se prvky (sloupy, světla)
rytmus pomáhá orientaci
👉 Mozek miluje vzory → rychle se zorientuje.
10. Kontext a očekávání
využití známých vzorců (např. vstup = dveře)
respekt kulturních zvyklostí
👉 Intuice vychází z minulých zkušeností.
11. Multisenzorický design
zvuk, vůně, teplota
nejen vizuální vjem
👉 Prostor „mluví“ všemi smysly.
12. Energetická / emocionální kvalita (abstraktnější rovina)
pocit klidu vs. napětí
otevřenost vs. uzavřenost
👉 Subjektivní, ale velmi silný faktor.
Jak to spojit do jednoho konceptu:
Intuitivní prostor =
prostředí, které člověk chápe a používá bez vědomého přemýšlení.
Pokud chceš, můžeme to posunout dál konkrétněji:
návrh interiéru / domu
UX (web nebo appka)
nebo třeba propojení s „Ekam / spirituální architekturou“, co jsi řešil dřív
Stačí říct směr 👍
Ux , web
Dobře, pojďme to zúžit čistě na UX / web a dát tomu konkrétní, použitelný rámec.
„Intuitivní prostor“ na webu = uživatel nemusí přemýšlet, kam kliknout nebo co dělat.
🔑 Základní UX koncepty intuitivního webu
1. Okamžitá orientace (0–3 sekundy)
Uživatel musí hned pochopit:
kde je
co to je za web
co má udělat dál
👉 Prakticky:
jasný headline (co nabízíš)
jeden hlavní CTA (např. „Začít“, „Koupit“)
2. Vizualní hierarchie
To nejdůležitější musí být nejvíc vidět.
👉 Použij:

velikost (H1 > H2 > text)
kontrast (barvy)
spacing (mezery = důležitost)
👉 Pravidlo:
co chceš, aby user udělal → musí být nejvýraznější
3. Přirozené čtení (F-pattern / Z-pattern)
Lidi nečtou, skenují:
desktop: F-pattern
landing page: Z-pattern
👉 Rozložení:
vlevo nahoře logo
vpravo nahoře akce
střed = sdělení
dolů = CTA
4. Jasné affordance (co je klikací)
Uživatel musí poznat bez přemýšlení:
tlačítko = klik
odkaz = klik
karta = interakce
👉 Nedělej:
„hezké, ale nejasné“ UI
👉 Dělej:
hover efekty
stíny
kontrastní buttony
5. Flow (tok uživatele)
Web má vést jako cesta:
👉 ideální flow:

příchod (landing)
pochopení
důvěra
akce
👉 Každá stránka má jednu hlavní akci
6. Redukce rozhodování (Hick’s Law)
Čím víc možností → tím horší UX.
👉 místo:

10 tlačítek → dej 1–3
složité menu → zjednoduš
👉 Minimalismus ≠ design
👉 Minimalismus = méně rozhodování
7. Konzistence
Stejné věci se chovají stejně:
buttony mají stejný styl
navigace funguje stejně
layout je opakovatelný
👉 mozek se „naučí systém“
8. Mikrointerakce
Malé reakce, které potvrzují akci:
hover
kliknutí
loading
animace
👉 dává pocit kontroly
9. Feedback (zpětná vazba)
User musí vědět:
co se stalo
jestli to funguje
👉 příklady:
„Odesláno“
loading spinner
error message
10. Rychlost = UX
Pomalý web = neintuitivní web
👉 cíle:

load < 2s
optimalizace obrázků
lazy loading
11. Kontext a očekávání
Nepřekvapuj zbytečně:
logo = homepage
košík = vpravo nahoře
menu = nahoře nebo hamburger
👉 inovace jen tam, kde dává smysl
12. Emoce + důvěra
Intuice = i pocit
👉 přidej:

reference
recenze
real fotky
jednoduchý jazyk
🧠 Shrnutí (jednou větou)
Intuitivní UX = uživatel dělá správné kroky bez přemýšlení.
⚡ Rychlý checklist (prakticky)
Vidím hned, co to je?
Vím, kam kliknout?
Je tam jen jedna hlavní akce?
Není to přeplácané?
Reaguje web na moje akce?
Pokud chceš, můžeme jít ještě víc konkrétně:
navrhnu ti wireframe (layout) stránky
nebo rozepíšu UX pro konkrétní projekt (třeba AI web, mining dashboard, cokoliv děláš)
