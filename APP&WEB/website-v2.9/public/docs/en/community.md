## How to contribute

1. **By mining** — every active node strengthens decentralization.
2. **By code** — fork the repo, open a PR, and describe the change in an auditable way.
3. **By reporting bugs** — create a GitHub issue with reproduction steps, logs, and expected behavior.
4. **By documentation** — help refine the public docs and the CZ/EN translation line.
5. **By community work** — help newcomers, spread practical knowledge, and keep public communication disciplined.
