# L4 Oasis — Consciousness Levels & XP

> Gamification for people, not for the protocol. Mining stays pure PoW — Oasis is the layer where activity becomes personal growth.

---

## Principle

ZION separates **work** (L1 mining, L3 AI compute) from **gamification** (L4 Oasis). Mining has no XP — block rewards are purely proportional to hashrate and PPLNS share.

**Oasis** sits above that: activity across the stack maps to **Consciousness Levels** — a nine-step personal evolution model inspired by the Kabbalistic Tree of Life.

```
L4 Oasis (XP, CL, badges, guilds, gamification)
    ↑ reads activity from
L3 (NCL AI tasks, WARP bridge, agent consciousness)
L2 (DAO voting, DeFi operations)
L1 (mining shares, block finds)
```

Oasis **never affects consensus** — no CL bonus in block rewards. It is a presentational and community layer only.

## XP decay — anti-gaming

To discourage passive farming, the system applies **decay**:

- **Grace period:** 7 days without activity  
- **Decay rate:** 1% per day after grace period  
- **Max decay:** 50% of total XP  
- **Reset:** Any activity stops decay  

```
Effective XP = Base XP × max(0.5, 1.0 - 0.01 × max(0, inactive_days - 7))
```

## L3 vs L4 — separation of concerns

| Aspect | L3 agent CL (internal) | L4 Oasis CL (player-facing) |
|--------|-------------------------|------------------------------|
| Levels | 6 (Dormant → Cosmic) | 9 (Physical → On The Star) |
| Purpose | AI agent capability gating | Human gamification |
| Effect | Allow/deny AI operations | Visual prestige, badges |
| Affects consensus? | No | No |
| Affects mining? | No | No |
| XP mapping | L3 × 10 = L4 | Own XP thresholds |

L3 Consciousness is an **internal metric** for AI agents — what operations the agent may perform. L4 Oasis is **public gamification** for human participants.
