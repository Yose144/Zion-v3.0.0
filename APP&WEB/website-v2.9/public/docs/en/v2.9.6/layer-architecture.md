**2040+** orbital station: astronomy, climate monitoring supporting L5, microgravity experiments, community-funded space science. Name approved by governance narrative.

Value flows: L1 emissions → humanitarian + L5/L6 funds; L4 activity burns fees (deflation); DAO steers grants; L5 outputs can co-finance L6; L6 observations feedback to L5 missions.
