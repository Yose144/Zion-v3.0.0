## Timeline

### Q1 2024 — Foundation ✅

- Genesis block (1. ledna 2024)
- Rust core implementace
- Základní P2P síť
- Prvotní testnet

### Q2–Q3 2024 — Core Development ✅

- Cosmic Harmony v1 konsenzus
- LMDB storage engine
- JSON-RPC API
- Basic mining pool

### Q4 2024 — Stabilizace ✅

- Cosmic Harmony v2 upgrade
- LWMA difficulty adjustment
- Multi-node testnet
- Docker deployment

### Q1 2025 — Native Awakening ✅

- Cosmic Harmony v3 (multi-algo)
- Nativní Rust binárky
- Stratum mining protokol
- Pool statistiky API

### Q2 2025 — v2.9.5 Release ✅

- Stabilní v2.9.5 release
- Docker compose stack
- Download stránka s binárkami
- Kompletní dokumentace

### Q3–Q4 2025 — Ekosystém 🔄

- Desktop wallet (Electron)
- Mobile wallet (React Native)
- Block explorer vylepšení
- Komunitní pool infrastruktura

### Q1 2026 — Pre-Mainnet 🔄

- Security audit (externí)
- Wallet finalizace
- Exchange integrace příprava

### Q2–Q3 2026 — Mainnet příprava 📅

- Finální audit
