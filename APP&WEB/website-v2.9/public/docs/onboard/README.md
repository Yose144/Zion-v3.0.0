# Onboard to ZION — Začni zde

Vítej v ZION TerraNova. Tento průvodce tě krok za krokem provede základy: peněženka, nód, těžba, most a první DApp.

## Co je ZION?

ZION je nativní Rust blockchain s Proof-of-Work konsensem, 6-decimal "flowers" ekonomikou a šesti-vrstvovou vizí TerraNova.

- **Mainnet Alpha:** 3.1.0
- **Konsensus:** Proof-of-Work, Cosmic Harmony Deeksha
- **Block time:** 60 s
- **Total supply:** 144 000 000 000 ZION
- **Block reward:** 5 400,067 ZION → Decade Decay (-20 % / 10 let), tail 725 ZION

## První kroky

1. **Peněženka** — vytvoř adresu a zazálohuj seed.
2. **Nód** — spusť si vlastní ZION node, nebo použij veřejný RPC.
3. **Těžba** — připoj se na veřejný pool a začni těžit.
4. **Bridge / WARP** — převeď ZION mezi L1 a L2.
5. **DApp** — postav si vlastní aplikaci na ZION JSON-RPC.
