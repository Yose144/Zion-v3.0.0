# Onboard to ZION — Začni zde

Vítej v ZION TerraNova. Tento průvodce tě krok za krokem provede základy — od desktopové aplikace pro úplné začátečníky až po pokročilejší témata.

## Nejrychlejší start — ZION Public Miner

Pokud jsi úplný nováček, začni **desktopovou aplikací ZION Public Miner**:

1. Stáhni instalátor pro Windows 11 nebo macOS.
2. Nainstaluj a povol spuštění v systémových nastaveních.
3. Vytvoř peněženku přímo v aplikaci.
4. Klikni na **Start Mining** — a těžíš.

Kompletní návod najdeš v kategorii **Desktop App** vlevo.

## Co je ZION?

ZION je nativní Rust blockchain s Proof-of-Work konsensem, 6-decimal "flowers" ekonomikou a šesti-vrstvovou vizí TerraNova.

- **Mainnet Alpha:** 3.1.0
- **Konsensus:** Proof-of-Work, Cosmic Harmony Deeksha
- **Block time:** 60 s
- **Total supply:** 144 000 000 000 ZION
- **Block reward:** 5 400,067 ZION → Decade Decay (-20 % / 10 let), tail 725 ZION

## Cesta dál

1. **Desktop App** — stáhni, nainstaluj, vytvoř peněženku a začni těžit.
2. **Peněženka** — jak zálohovat seed a spravovat adresy.
3. **Těžba** — principy a pokročilejší nastavení.
4. **Nód** — spusť si vlastní ZION node.
5. **Bridge / WARP** — převeď ZION mezi L1 a L2.
6. **První DApp** — postav aplikaci na ZION JSON-RPC.
