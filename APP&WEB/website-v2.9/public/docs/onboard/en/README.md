## What ZION is — in three sentences

**ZION is a blockchain you can verify, not just trust.** It has been running since January 1, 2026, a new block every 60 seconds, with open-source code that anyone can read.

**No one got VIP access.** No ICO, no presale, no secret allocations. Anyone who wants ZION mines it — or gets it from someone who mined it.

### Builder — "I want to carry a piece of the bridge"

Your computer can be a node of the new network:

```bash
# 1. Download the code
git clone https://github.com/Zion-TerraNova/v3-Mainnet.git
cd v3-Mainnet/V3

# 2. Build the CLI (5–15 minutes)
cargo build --release -p zion-cli

# 3. Run the interactive wizard, wallet, node, or miner
./target/release/zion
```

One binary, an interactive menu, no cryptography degree required. You can mine on an ordinary CPU or GPU — the algorithm is designed so that a home computer has a chance.
