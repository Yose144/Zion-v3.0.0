# For the curious — technical FAQ

This section is for those who want to go beneath the surface. You'll find practical guides here on how to install the desktop application, create a wallet, run your own node, mine, use the bridge, or build your first DApp.

> **The marketing story and philosophy of ZION can be found in the categories above.** Technical details are here for honesty — so you can verify that behind the story stands working code.

## What you'll find here

- **Desktop App** — ZION Public Miner for Windows 11 and macOS. The fastest entry for beginners.
- **Wallet** — creation, seed backup, and safe use of your address.
- **Mining** — principles, pool, and advanced settings.
- **Node** — build, systemd service, and public RPC.
- **Bridge / WARP** — wZION, the bridge between L1 and L2, and the API.
- **First DApp** — build an app on ZION JSON-RPC.
