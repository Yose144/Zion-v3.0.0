# L4 Oasis — Consciousness Levels & XP systém

> Gamifikace pro lidi, ne pro protokol. Mining zůstává čistý PoW — Oasis je vrstva, kde se aktivita mění v osobní růst.

---

## Princip

ZION separuje **práci** (L1 mining, L3 AI compute) od **gamifikace** (L4 Oasis). Mining neobsahuje žádný XP systém — block rewards jsou čistě proporcionální hashrate a PPLNS podílu.

**Oasis** je vrstva nad tím, kde se různé aktivity napříč celým stackem promítají do **Consciousness Levels** — systému osobní evoluce s 9 úrovněmi inspirovanými kabalistickým Stromem života.

```
L4 Oasis (XP, CL, badges, guildy, gamifikace)
    ↑ čte aktivitu z
L3 (NCL AI tasky, WARP bridge, agent consciousness)
L2 (DAO voting, DeFi operace)
L1 (mining shares, blokové nálezy)
```

Oasis **nikdy neovlivňuje konsenzus** — žádný CL bonus do block rewards. Je to čistě presentační a komunitní vrstva.

## XP Decay — ochrana proti gaming

Aby se zabránilo pasivnímu farmingu, systém implementuje **decay**:

- **Grace period:** 7 dní bez aktivity
- **Decay rate:** 1% za den po grace period
- **Max decay:** 50% celkového XP
- **Reset:** Jakákoliv aktivita zastaví decay

```
Efektivní XP = Base XP × max(0.5, 1.0 - 0.01 × max(0, inactive_days - 7))
```

## L3 vs L4 — separace concerns

| Aspekt | L3 Agent CL (interní) | L4 Oasis CL (hráčský) |
|--------|----------------------|----------------------|
| Úrovně | 6 (Dormant → Cosmic) | 9 (Physical → On The Star) |
| Účel | AI agentní capability gating | Gamifikace pro lidi |
| Efekt | Povolení/blokace AI operací | Vizuální prestiž, badges |
| Ovlivňuje konsenzus? | Ne | Ne |
| Ovlivňuje mining? | Ne | Ne |
| XP mapování | L3 × 10 = L4 | Vlastní XP práhy |

L3 Consciousness je **interní metrika** pro AI agenty — určuje, jaké operace agent smí provádět. L4 Oasis je **veřejná gamifikace** pro lidské účastníky.
