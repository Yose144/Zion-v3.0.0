## Kosmologie — Ekam Deeksha PoW

ZION mining algoritmus není jen hashovací funkce — je to **šestistupňový kosmologický pipeline**, kde každý krok odráží stvoření vesmíru:

```
Input: header + nonce
  │
  ├── 1. Keccak-256      → Hiranyagarbha — Zlaté vejce (kondenzace)
  ├── 2. SHA3-512         → Brahma — Stvořitel (expanze)
  ├── 3. Golden Matrix φ  → Yantra — Posvátná geometrie (φ = 1.618...)
  ├── 4. MemoryHard       → Karma — Práce v čase
  │      256 KiB scratchpad, 4 passes
  ├── 5. NPU Mix INT8     → Chit — Vědomí
  │      Epoch-rotating topology (2016 bloků)
  └── 6. Cosmic Fusion    → Samadhi — Sjednocení
         Keccak + AES-NI, 4 rounds
```

Těžba ZION je **rituál** — ne proto, že by to bylo esoterické, ale proto, že kosmologické principy (zlatý řez, karmic work, epochy proměny) dávají algoritmu přirozené vlastnosti: **ASIC rezistenci** (memory-hard scratchpad + iracionální φ transformace) a **adaptabilitu** (epoch-rotating NPU topologie).

## NCL — Neural Compute Layer (L3)

Minery nevyužívají 100% GPU na hashování. NCL přidává **druhý revenue stream** — placené AI inference:

```
Tradiční mining:    100% GPU → Block rewards
ZION AI Native:      50% GPU → ZION mining + merged mining (ETC/Nexus)
                     25% GPU → Multi-algo profit switch (ERG/RVN/KAS/ALPH)
                     25% GPU → NCL AI inference → USD/BTC/ZION
```

Mining má **vždy prioritu** — NCL využívá mezery a idle cykly. Scheduling: 70% mining / 30% AI (konfigurovatelné 50–90% mining).
