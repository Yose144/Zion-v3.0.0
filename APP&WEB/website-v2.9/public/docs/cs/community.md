## Jak přispět

1. **Těžbou** — každý aktivní node posiluje decentralizaci sítě.
2. **Kódem** — forkni repo, připrav PR a popiš změnu auditovatelně.
3. **Reportováním bugů** — vytvoř issue na GitHubu s reprodukcí, logy a očekávaným chováním.
4. **Dokumentací** — pomoz zpřesnit tuto veřejnou dokumentaci a CZ/EN překlady.
5. **Komunitou** — pomáhej nováčkům, šiř know-how a udržuj veřejnou komunikaci věcnou.
