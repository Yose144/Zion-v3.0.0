# Lumi — Jazyk Světla

> **Stav:** Specifikace v1.0 — kanonická verze
> **Původ:** Terra Nova — Zlatý Kompas Nové Země
> **Cíl:** Konstruovaný univerzální jazyk (conlang) pro ZION ekosystém — lingvistický most, ve kterém se setkávají kultury celého světa.

---

## 1. Co je Lumi

**Lumi** je **konstruovaný univerzální jazyk** pro ZION ekosystém. Není náhradou za přirozené jazyky — je to **most** mezi nimi.

Jméno *Lumi* funguje v mnoha jazycích současně:

- **Latina:** *lūmen* — světlo
- **Italština / portugalština:** *lume / luma* — světlo, lampa
- **Finština:** *lumi* — sníh (čistá bílá)
- **Havajština:** *lumi* — pokoj, místnost (prostor)

**Slovo, které funguje univerzálně — to je základ filozofie.**

---

## 2. Proč nový jazyk

1. **Angličtina je dominantní, ale exkluzivní.** Globální lingua franca, která nese kulturní hierarchii.
2. **Přirozené jazyky neunesou techno-spirituální slovník 21. století.** Sanskrit má slova pro meditaci, ne pro blockchain. Angličtina má slova pro trh, ne pro mantru.
3. **Esperanto bylo silný pokus, ale kulturně eurocentrické** — ~80 % slovní zásoby z románských jazyků.

**Cíl Lumi:** jazyk nesoucí DNA všech velkých tradic světa současně — sanskrit (kosmologie, meditace), havajština (dech, oceán), lakota (kruh, příbuznost), hebrejština, arabština, čínština, tibetština, portugalština, hindi, yoruba/akan (*ubuntu*), slovanské jazyky i angličtina jako strukturní pojivo.

## 3. Design — snadné a hluboké zároveň

| Vrstva | Design |
|---|---|
| **Fonetika** | 20 fonémů — **5 vokálů** (a, e, i, o, u) + **15 souhlásek**. Bez tónů, bez dlouhých/krátkých rozdílů, bez diftongů jako fonémů |
| **Gramatika** | **Aglutinační** (stavebnicová), bez nepravidelných sloves, bez gramatických rodů |
| **Sémantika** | Každé klíčové slovo nese více vrstev významu (jako sanskrit); slova tvoří propojená sémantická pole |
| **Posvátná numerologie** | Jádro slovníku = **108 slov** (posvátné číslo); rozšíření přes **70 Light Tones** |
| **Psaní** | Latinka 1:1 s výslovností — vidíš slovo, víš výslovnost. Bez výjimek |

Podrobnosti: `phonetics.md` (zvuky), `core-108.md` (slovník), `light-tones.md` (frekvenční vrstva).

## 4. Lidská a strojová vrstva

ZION ekosystém obsahuje **QDL/ZQAL** — strojově čitelný kvantový programovací jazyk se **70 Light Language Tones** (posvátné frekvence mapované na koncepty).

- **QDL/ZQAL** = stroj-čitelná vrstva
- **Lumi** = lidsky mluvitelná vrstva
- **Společná páteř:** 70 Light Tones funguje v obou

Když recituješ Lumi mantru, aktivuješ specifické tóny — např. *„Aum aloha pono"* rezonuje s tóny Solar_Union, Rama_Dharma a Thrones_Justice (viz `light-tones.md`).

## 5. Etika a hranice

### Co Lumi není

1. **Není náhrada** za přirozené jazyky. Tvá mateřština je svatá — Lumi je doplněk, most.
2. **Není náboženství.** Je to lingvistický experiment s otevřeným zdrojem.
3. **Není monolit.** Lumi je živá, komunita ji mění, dialekty jsou vítány.
4. **Není přivlastnění.** Slova vypůjčená z konkrétních tradic jsou citována s úctou.

### Co Lumi je

1. **Pokus o lingvistickou rovnost** — žádný kontinent není dominant.
2. **Open source** — pravidla, slovník i gramatika jsou publikované, kdokoliv může přispět.
3. **Posvátná funkce** — modlitby, mantry, ceremonie.
4. **Praktická funkce** — denní komunikace v multilingvální komunitě ZIONu.
