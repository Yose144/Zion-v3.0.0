# Lumi — Jádrový Slovník 108

> **Stav:** Specifikace v1.0 — kanonická verze
> **Cíl:** Jádro slovníku — 108 slotů v 9 tematických skupinách (107 definovaných slov + 1 otevřený slot pro komunitní rozšíření), každé s etymologií z konkrétní světové tradice.

> *„108 jmen Šivy. 108 korálků v mala. 108 stupňů mezi vědomími. 108 slov jádra Lumi."*

---

## Proč 108

- **Hinduismus:** 108 jmen Šivy, 108 Upanišad, 108 korálků v *mala*
- **Buddhismus:** 108 *kleshas* k překonání
- **Astronomie:** vzdálenost Země–Slunce ≈ 108× průměr Slunce; Země–Měsíc ≈ 108× průměr Měsíce
- **Matematika:** 1¹ × 2² × 3³ = 108

108 slov stačí na většinu konverzace — a jde se je naučit za měsíc.

## Etymologický rozklad

| Jazyková rodina | Podíl | Příklady |
|---|---|---|
| Indo-evropská — sanskrit/hindi | ~50 % | mana, dharma, prana, mantra |
| Polynéská | ~12 % | aloha, ohana, moana, pono, kapu |
| Romance | ~10 % | lumi, per, se, a, o |
| Univerzální / multi-source | ~19 % | mi, tu, na, ta |
| Východní Asie | ~5 % | ka, ye, hana |
| Lakota / domorodá Amerika | ~3 % | mitar, wakan |
| Bantu / africká | ~1 % | ubuntu |

Sanskrit dominuje, protože byl historickou lingua francou posvátné slovní zásoby napříč Asií. Polynéština je silně zastoupena pro přirozeně otevřenou vokální strukturu.

## Slovotvorba — z 108 na tisíce

S aglutinační gramatikou lze z jádra vytvořit odhadem 15 000–30 000 kompozit:

- **lumi-sona** = světlo-řeč = jazyk Lumi
- **mitar-ohana** = příbuzný-rodina = rozšířená rodinná síť
- **pono-kar** = rovnováha-konání = governance
- **aloha-bhumi** = láska-země = environmentalismus
- **hana-em** = květina-místo = zahrada
- **kala-chakra** = čas-kolo = kalendář, cyklus
- **bodhi-bhumi** = probuzení-země = místo osvícení

1. *„Já světlo říkám."* → **Mi lumi sona.**

4. *„Květina v zahradě stojí."* → **Hana hana-em-a stha.**
