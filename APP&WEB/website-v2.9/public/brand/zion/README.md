# ZION Z-Tree Logo — Concept v1

Hand-coded vector mark: the letter **Z** built from a tree of life — the top
bar fans into a triangular-leaf crown, the diagonal is the trunk, the bottom
bar dissolves into roots. Gold/cosmic primary palette with a small green
accent nodding to the original `Z.gif` matrix mark.

> **Note on how this was made:** these are hand-authored SVG shapes
> generated procedurally with a small Python script (`generate_zion_logo.py`,
> kept alongside this README's source in the session — ask if you want it
> copied into the repo), not AI image generation. It's a solid first-draft
> concept, not a polished professional illustration. If you want the
> organic, painterly quality of `LogoNew.jpg` / the reference `logo.jpeg`,
> that likely needs either a real designer pass or an AI image-generation
> tool, using this concept (and this README) as the brief.
