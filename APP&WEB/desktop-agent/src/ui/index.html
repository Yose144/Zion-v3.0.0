Lock ZION on L1 → receive wZION on Base

Send ZION to the bridge vault address on L1 with the generated memo. The Rust relay monitors L1 and automatically mints wZION to your Base address.

Burn wZION on Base → receive ZION on L1

Use the mobile wallet to sign and broadcast the bridgeBurn() transaction, or call the contract directly via BaseScan write interface. The Rust relay will release L1 ZION after confirmation.

burnId: unique bytes32 (e.g. 0x000...001)
