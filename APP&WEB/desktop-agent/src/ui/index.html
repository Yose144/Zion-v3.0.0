Security & Antivirus

Těžební software může být falešně detekován antivirem. Zde můžete zkontrolovat stav a opravit problémy.

🪟 Windows — Kompletní průvodce

1. SmartScreen při instalaci

Při spuštění instalátoru Windows zobrazí modré okno „SmartScreen ochránil tento počítač":

  1. Klikněte na „Více informací" (malý odkaz vlevo dole)
  2. Zobrazí se tlačítko „Přesto spustit" → klikněte na něj
  3. Instalace proběhne normálně

ℹ️ SmartScreen blokuje všechny nové/nepodepsané aplikace. Jakmile bude ZION Miner digitálně podepsán, tato hláška zmizí.

2. Windows Defender — smazaná binárka

Defender může po instalaci smazat zion-universal-miner.exe jako „Potentially Unwanted App" (PUA). Obnovení:

  1. Otevřete Windows Security (Start → napište „Zabezpečení")
  2. Klikněte Ochrana před viry a hrozbami
  3. Klikněte „Historie ochrany"
  4. Najděte zablokovanou položku → rozbalte → klikněte „Akce → Povolit na zařízení"

3. Přidání výjimky (doporučeno)

Aby Defender neblokoval miner opakovaně:

  1. Windows Security → Ochrana před viry → Spravovat nastavení
  2. Sjeďte dolů k „Výjimky" → klikněte „Přidat nebo odebrat vyloučení"
  3. Klikněte + Přidat vyloučení → Složka
  4. Vyberte instalační složku ZION Mineru:
C:\Users\VaseJmeno\AppData\Local\Programs\zion-desktop-agent\ C:\Program Files\ZION Miner\

4. PowerShell příkazy (pro pokročilé)

Spusťte PowerShell jako Administrator:

# Přidání výjimky na složku
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\Programs\zion-desktop-agent"

# Obnovení smazaného souboru z karantény
Get-MpThreatDetection | Where-Object { $_.Resources -like "*zion*" }
Remove-MpThreat -ThreatID <ID_z_výpisu>

# Vypnutí PUA detekce (nedoporučeno pro běžné uživatele)
Set-MpPreference -PUAProtection 0

5. Quick Start — Windows

# 1. Stáhněte installer z GitHub Releases
# 2. Spusťte .exe → SmartScreen → "Více informací" → "Přesto spustit"
# 3. Nainstalujte (výchozí složka je OK)
# 4. Pokud Defender smaže miner:
# → Otevřete Windows Security → Historie ochrany → Povolit
# → Přidejte výjimku (viz výše)
# 5. Spusťte ZION Miner z plochy nebo Start menu
# 6. Zadejte wallet adresu → klikněte Start Mining
# ✅ Pokud Rust miner nefunguje, app automaticky přepne na Python

💡 Pokud Defender smaže miner, aplikace automaticky přepne na Python fallback — těží se dál.

🍎 macOS — Kompletní průvodce

1. Gatekeeper — „Aplikace nemůže být otevřena"

macOS blokuje stažené neregistrované aplikace. Tři způsoby obejití:

  1. Pravý klik → Otevřít — místo dvojkliku klikněte pravým → vyberte „Otevřít" → potvrďte v dialogu
  2. System Settings → Privacy & Security → dole najdete hlášku „ZION Miner was blocked" → klikněte „Open Anyway"
  3. Terminál — viz příkazy níže

2. Odstranění quarantine příznaku

Stažené soubory dostanou atribut com.apple.quarantine. Odebrání:

# Odebrání quarantine z celé aplikace
xattr -dr com.apple.quarantine /Applications/ZION\ Miner.app

# Nebo jen z DMG před instalací
xattr -dr com.apple.quarantine ~/Downloads/ZION*.dmg

# Ověření — nesmí zobrazit "quarantine"
xattr -l /Applications/ZION\ Miner.app

3. Oprávnění ke spuštění minerů

Pokud miner hlásí „Permission denied":

# Nastavení execute permissions na miner binárky
chmod +x /Applications/ZION\ Miner.app/Contents/Resources/zion-universal-miner
chmod +x /Applications/ZION\ Miner.app/Contents/Resources/zion-miner

# Nebo pro dev režim
chmod +x ./resources/zion-universal-miner
chmod +x ./resources/zion-miner

4. Firewall — povolení síťového přístupu

macOS firewall se může zeptat na povolení síťového přístupu:

  1. V dialogu „Do you want ZION Miner to accept incoming connections?" → klikněte „Allow"
  2. Nebo: System Settings → Network → Firewall → Options → přidejte ZION Miner do seznamu

5. Quick Start — macOS

# 1. Stáhněte .dmg z GitHub Releases
# 2. Odstraňte quarantine (volitelné — app to dělá automaticky)
xattr -dr com.apple.quarantine ~/Downloads/ZION*.dmg

# 3. Otevřete DMG a přetáhněte do Applications
# 4. První spuštění: Pravý klik → Otevřít → potvrdit
# 5. Povolte firewall pokud se zeptá
# 6. Zadejte wallet adresu → Start Mining
# ✅ Hotovo!

💡 Aplikace automaticky opravuje quarantine příznak a permissions při každém spuštění.

❓ FAQ — Často kladené otázky

Q: Je ZION Miner virus?
Ne. Těžební software má podobné chování jako malware (vysoké využití CPU/GPU, síťová komunikace), proto ho antiviry občas falešně detekují jako „PUA" (Potentially Unwanted Application). Kód je open-source a lze si ho ověřit.
Q: Proč Windows Defender smaže miner po instalaci?
Defender má heuristickou detekci kryptominerů. Řešení: přidejte výjimku na instalační složku (viz návod výše). Aplikace automaticky přepne na Python miner jako zálohu.
Q: Na macOS se zobrazuje „App is damaged" nebo „Cannot be opened"
Pravý klik → Otevřít místo dvojkliku. Nebo v Terminálu: xattr -dr com.apple.quarantine /Applications/ZION\ Miner.app
Q: Miner se spustil, ale hash rate je 0
Zkontrolujte: 1) Je zadaná správná wallet adresa? 2) Je připojení k poolu aktivní? (zelená tečka v Dashboard) 3) Zkuste přepnout backend na „Python" v nastavení, pokud Rust miner nefunguje.
Q: Jak zapnu GPU mining?
GPU mining vyžaduje OpenCL driver (AMD/Intel) nebo CUDA (NVIDIA). Na macOS Apple Silicon se použije Metal automaticky. Zkontrolujte, že máte nainstalované GPU drivery. V nastavení vyberte „GPU" mód.
Q: Jak funguje auto-update?
Při startu (a manuálně v About → Updates) aplikace zkontroluje GitHub Releases. Pokud existuje nová verze, nabídne stažení a instalaci. Na Windows se nainstaluje přes NSIS installer automaticky.
Q: Můžu těžit na více počítačích se stejnou peněženkou?
Ano. Stačí použít stejnou wallet adresu na všech počítačích. Pool přiřadí hashrate ke stejnému účtu.
