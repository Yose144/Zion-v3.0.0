María Mayor · Nossa Senhora de Fátima · María de las Nieves – patrons of Zion.


My pilgrim's journey began in 2022, when I set out on the Camino de Santiago from Porto. It wasn't a vacation or a sports achievement. It was a challenge – physical, mental, and spiritual.

On this path, I received an initiation described in the short book Genesis by Marie Mayor, handed to me in Pontevedra. It wasn't a moment of enlightenment, more like a quiet realization. A simple sentence that etched itself deep within me:

“You will find the lost Paradise.”

Back then, I had no idea what it meant. I only knew that the journey didn't end in Santiago.

Honestly – if it weren't for my daughter Sarah, I probably would have stopped at some point. Her voice was often the only thing keeping me going:

“Dad, don't give up.”

And so I kept walking. Step by step until the end.


When a Pilgrim Meets Code


It never occurred to me how strongly this spiritual journey would one day connect with my technical IT developer reality. From September 2025, I found myself in one of the most demanding development sprints of my life.

The ZION project grew alongside me.

From Zion Mainnet 2.5 to today's version 3.1.0 – MAINNET ALPHA, which is already running on Rust core.

It's not about “another coin.” It's about a living system built layer by layer:

  • core
  • mining
  • pool
  • nodes
  • P2P network
  • wallets
  • mobile app (in development)
  • desktop miner
  • and other layers, warp, ai native, etc.

It's demanding. Mentally, technically, humanly. And so far, it all rests on one person.


Pre-Mainnet Launch – The Moment of Truth


Now comes the key point: Pre-Mainnet Launch.

If everything succeeds, I want to launch Mainnet this year, but realistically and honestly – only the basic L1 layer.

That means:

  • no Warp
  • no Oasis
  • no AI Native/DAO
  • no XP system

Just the essentials:

  • core
  • nodes
  • pool
  • P2P
  • mining

So that the network can take a breath and start existing on its own.

The basic reward will be:

5400 ZION per block.

The pool will run on PPLNS and a combination of PoW with our Cosmic Harmony v3 algorithm (v2 is ASIC-resistant, v3 is its next evolution).


Premine, Responsibility, and Long Horizon


Premine is not a shortcut. It's a commitment.
