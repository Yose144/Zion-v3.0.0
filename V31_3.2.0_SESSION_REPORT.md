## 2. Klíčové změny v `2686ac4db`

### 2.1 u128 string serde centralizovaná v `zion-l1-types`

- Nový modul `V31/L1/types/src/u128_str.rs` poskytuje sdílené `serialize`/`deserialize` helpery a podmodul `u128_str::map` pro `HashMap<String, u128>`.
- Podporuje:
  - desetinné řetězce (`"12345"`),
  - holá JSON čísla (`u64`/`u128`/`i64`/`i128`),
  - přesné nezáporné `f64` hodnoty,
  - odmítá záporná čísla a nepřesné floaty.
- `V31/L1/types/src/amount.rs` nyní serializuje `Amount` jako desetinný řetězec a deserializuje přes `deserialize_any` s vlastním `Visitor`.
- Konzumenti migrováni:
  - `V31/L1/core/src/node_runtime.rs`
  - `V31/L1/core/src/v3_checkpoint.rs`
  - `V31/L1/pool/src/v3_pplns.rs`
  - `V31/L2/multichain/src/warp/protocol.rs`
- Odebrány duplicitní lokální serde helper moduly.

> **Poznámka k `arbitrary_precision`:** `V31/STATUS.md` zmiňuje `serde_json` s feature `arbitrary_precision`, ale `V31/Cargo.toml` má aktuálně `serde_json = "1"` bez této feature. Kanonickým řešením u128 JSON je `zion_l1_types::u128_str` string serde.
