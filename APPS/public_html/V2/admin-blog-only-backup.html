Jak publikovat článek

  1. Vyplňte formulář — nadpis, popis, kategorii, obsah v Markdownu
  2. Zkontrolujte v panelu Náhled
  3. V panelu Export stáhněte HTML soubor
  4. Nahrajte HTML do složky blog/ na serveru
  5. Zkopírujte JSON záznam a přidejte ho do pole BLOG_POSTS v souboru blog-posts.js
  6. Hotovo! Článek se automaticky zobrazí na blogu.
