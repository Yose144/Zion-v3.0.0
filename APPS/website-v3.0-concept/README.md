# ZION Web3.0 - Consciousness Portal

## 🌟 Konzept

Originální Web3.0 portál založený na věrstvích vědomí (L1-L6). Každá stránka představuje jednu vrstvu:

- **L1 Core** - Blockchain, Mining, Consensus
- **L2 Bridge/DAO** - Cross-chain, Governance
- **L3 WARP/NCL** - Universal bridge, AI compute
- **L4 OASIS** - Consciousness Mining Game
- **L5 Free World** - Humanitarian communities
- **L6 Issobella** - Space station network

## 🎨 Design Principy

1. **Living Geometry** - SVG sacred geometry patterns
2. **Consciousness Colors** - Gradient od cyan → purple → pink
3. **Neural Animation** - 3D modely s pulzujícími uzlivy
4. **Glass Morphism** - Background s blur efekty
5. **Responsive First** - Mobile-first design

## 📱 Stránky

- `/` - Consciousness Portal (landing)
- `/neuron` - Neuron Network visualization
- `/wallet` - Fractal Wallet
- `/hiran` - HIRAN AI Chat
