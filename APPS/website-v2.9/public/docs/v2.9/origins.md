## The Genesis Day

**September 26, 2025** is considered the technical genesis of ZION TerraNova. On this day, the Cosmic Harmony algorithm was designed from first principles and the first mining session ran successfully on TypeScript pool infrastructure.

This was not yet a blockchain — it was a TypeScript pool implementation proving that the algorithm concept worked. But it established all the core ideas: the 4-phase hash design, the memory-hard Galactic Matrix, the Golden Ratio mixing, and the vision of a CPU-friendly yet ASIC-resistant PoW.

---

## Algorithm Design: ZH-2025

The original algorithm document was titled "ZION-COSMIC-HARMONY (ZH-2025)":

```
🌟 COSMIC HARMONY = QUANTUM RESISTANCE + GALACTIC EFFICIENCY + STELLAR BEAUTY 🌟

    Phase 1: QUANTUM SEED
       Blake3 + Keccak256 + SHA3-512 triple hash

    Phase 2: GALACTIC MATRIX (2MB)
       Dynamic memory dance with Fibonacci spiral access

    Phase 3: STELLAR HARMONY
       Golden ratio (φ = 1.618...) mixing

    Phase 4: COSMIC PROOF
       Final hash against difficulty target
```

This 4-phase structure survived unchanged through all versions — CHv1 (Python), CHv2 (Python + C), and CHv3 (Rust). Only the implementation changed; the algorithm design stayed constant from this first document.

## First Mining Session

On September 26–27, 2025, the first successful GPU mining session using the ZH-2025 algorithm was documented:

- Hardware: AMD GPU (OpenCL)
- Pool: TypeScript Stratum server
- Result: First valid shares submitted
- Algorithm: ZH-2025 prototype

This session confirmed the algorithm design was viable — shares were being found at the expected difficulty, GPU outperformed CPU as expected, and the memory-hard design was working.

## Why "TerraNova"

ZION TerraNova — "New Earth" in Latin. The project was conceived with a mission extending beyond cryptocurrency into planetary-scale infrastructure: clean energy, humanitarian projects, and eventually an Earth orbital station (L6 — ZION Issobella). The blockchain is L1 in a 6-layer civilization infrastructure.

The name "On the Star" (v2.9.6) comes from this same philosophy — a blockchain literally designed to reach the stars.
