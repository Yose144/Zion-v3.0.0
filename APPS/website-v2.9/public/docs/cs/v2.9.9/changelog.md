# Changelog — v2.9.9 (Pure Code)

## Delta oproti v2.9.8

- Čištění legacy kódu v souborech mineru, poolu a runtime.
- Sjednocení pojmenování a odstranění mrtvých dispatch větví.
- Redukce duplicitních fallback cest.
- Zdokumentovaná migrační strategie směrem k čistému V3 tracku.

## Co zůstává beze změny

- Záměr konsenzu: beze změny sémantiky hashů.
- Veřejná launch politika: launch gate zůstává pod closure důkazy.
- Kontext runtime: kanonická cesta v2.9.8 zůstává referenčním základem.

## Proč na tom záleží

Fáze Pure Code zvyšuje auditovatelnost, snižuje provozní riziko a zjednodušuje přenos do V3 bez historického balastu.
