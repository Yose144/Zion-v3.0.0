# Governance — ZION v2.9.5

---

## Model správy

ZION využívá hybridní governance model:

1. **On-chain** — DAO Treasury (4 mld ZION) spravovaný hlasováním
2. **Off-chain** — komunitní diskuse přes GitHub Issues a Discord
3. **Immutable Core** — základní parametry jsou neměnné

---

## Neměnné parametry

Tyto parametry jsou pevně zakódované a nelze je změnit žádným hlasováním:

| Parametr | Hodnota | Důvod |
|----------|---------|-------|
| Celková emise | 144 mld ZION | Ochrana proti inflaci |
| Block reward | 5 400,067 ZION | Předvídatelná emise |
| Halving | Ne | Konstantní odměna pro minery |
| Fee policy | Burn | Deflační mechanismus |
| Genesis timestamp | Jan 1, 2024 | Historická integrita |
| Premine distribuce | 16,28 mld | Transparentní alokace |

---

## DAO Treasury

- **Fond**: 4 mld ZION (24,6 % premine)
- **Účel**: financování vývoje, infrastruktury, grantů
- **Správa**: komunitní hlasování
- **Transparentnost**: všechny výdaje on-chain

---

## Návrhy změn (Proposals)

1. Vytvoř GitHub Issue s prefixem `[PROPOSAL]`
2. Komunita diskutuje (min. 7 dní)
3. Hlasování — drží ZION = hlas
4. Implementace při dostatečné podpoře

---

## Co lze měnit hlasováním

- Alokace DAO Treasury fondů
- Parametry mempoolu
- P2P limity
- RPC konfigurace
- Přidání nových funkcí

---

## Co nelze měnit

- Emisní křivka
- Block reward
- Premine distribuce
- Konsenzus algoritmus (vyžaduje hard fork + širokou shodu)
