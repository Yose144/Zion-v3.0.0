fix(beam): load beamhash_solver.cl instead of beamhash_kernel.cl

The BeamHash III GPU solver calls cleanUp, beamHashIII_seed, and
beamHashIII_R1..R5 kernels, which are all defined in
csrc/opencl/beamhash_solver.cl. But ensure_proque was asked to load
beamhash_kernel.cl (which only contains the SipHash-2-4 hash generation
kernel), so clCreateKernel("cleanUp") failed with CL_INVALID_KERNEL_NAME
(-46) on every BEAM batch.

Also add beamhash_solver.cl to the include_str! dispatch table in
ensure_proque so the embedded kernel source is available at runtime.
