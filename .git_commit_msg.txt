fix(beam): detect BeamStratum inline error codes in login response

beam.2miners.com returns login errors as inline code/description
fields (e.g. code:-32003 "Invalid address") rather than a standard
JSON-RPC error object. The previous code only checked resp["error"],
so an "Invalid address" response was silently treated as a successful
login, causing an immediate disconnect loop with no diagnostic.

Now beam_login also checks for a negative code field and bails with
the description, so the multiplexer reports the real cause instead of
"connection closed by remote - reconnecting in 5s".
