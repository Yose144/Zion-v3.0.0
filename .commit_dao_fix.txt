fix(dao): wire L1 scanner metrics counter + rebuild binary

The L1 scanner was not incrementing the l1_blocks_scanned_total
Prometheus counter, making it impossible to monitor scanner progress
via /metrics. Added Arc<DaoMetrics> to L1Scanner via with_metrics()
builder and increment the counter after each scanned block.

Also rebuilt and redeployed the DAO binary on the Edge server to fix
a persistent "Connection refused" error when connecting to the L1
node RPC at 127.0.0.1:8443. The rebuilt binary connects successfully.

Additionally fixed the pool service systemd unit to use
KillMode=control-group and added ExecStartPre to kill any zombie
process holding port 8444, preventing recurring "Address already
in use" startup failures.
