## 4. Umělá gravitace (shrnutí)

Proč: zdraví posádky, prevence atrofie svalů a kostí, VIIP, psychika.

### Fyzika

```
a = ω² × r
g_eff = a / 9,81
```

### Doporučená konfigurace v1.0

| Parametr | Hodnota |
|----------|---------|
| Hlavní torus | průměr 200 m (r=100 m) |
| Bydlení | 0,38 g (Mars) |
| Úhlová rychlost | ~2,1 RPM pro 0,5 g; ~1,9 RPM pro 0,38 g |
| Rehabilitační centrifuga | r=12 m, 1,0 g, 12 RPM |
| Mikrogravity lab | u těžiště trusu |

### Designové varianty

- **Velký torus** — nejlepší pro bydlení, nízké Coriolis, vysoká hmotnost.
- **Malá centrifuga** — kompaktní, ale vysoké RPM; vhodná pro cvičení.
- **Tether-counterweight** — lehký, ale složitý docking a dynamika.
- **Hybrid** — doporučený: torus + centrifuga + mikrogravity lab.
