## Účel

- Shromáždit všechny klíčové materiály pro L6 na jednom místě.
- Poskytnout modelu dostatek kontextu: historie, architektura, technologie, lidské faktory, ekonomika, timeline.
- Umožnit iteraci návrhů a “what-if” analýzy pro stavbu stanice, kvantový motor a umělou gravitaci.

## Jak používat jako GPT kontext

1. Začněte tímto `README.md` — pochopíte strukturu a cíl.
2. Přečtěte [`Architektura.md`](Architektura.md) pro celkový obraz stanice.
3. Projděte [`Kvantovy_Motor.md`](Kvantovy_Motor.md) a [`Umela_Gravitace.md`](Umela_Gravitace.md) podle toho, na co se ptáte.
4. [`Histori.md`](Histori.md) poskytuje inspiraci z reálné historie stanic.
5. [`GPT_Podklady.md`](GPT_Podklady.md) můžete zkopírovat jako jeden kontextový blok.
