# Modely pro 3D betlém

Ateliér doručuje vlastní kopie šesti modelů z [katalogu Nirvany](../../../../../apps/nirvana/public/models/avatars). Scéna je používá v klidové póze. Pozice vrcholů, normály, UV souřadnice a indexy jsou shodné s originály. Textury mají nejvýše 768 × 768 bodů, animace a kostra jsou pro tento pohled vynechané.
