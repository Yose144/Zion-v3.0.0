### P0 — Blockers (Must Fix)

| # | Issue | Impact | Root Cause | Fix Plan |
|---|---|---|---|---|
| 1 | **Node2 metrics + WS port collision** | Node2 can't expose metrics/WS | Both nodes default to 9115/8445 | Set `ZION_METRICS_BIND=0.0.0.0:9116` and `ZION_WEBSOCKET_BIND=0.0.0.0:8447` in `start-node2.sh` |
| 2 | **Miner running on CPU only** | Hashrate ~50x lower than GPU | No OpenCL/CUDA runtime in environment; `dcr[0] gpu unavailable` | Install ROCm/OpenCL drivers or run on GPU-capable host |
| 3 | **Payout system still uses single pool wallet** for miner share | 89% goes back to pool wallet for PPLNS redistribution | Config design — all fee addresses point to pool wallet | **Expected behavior** for solo-miner-test setup; for mainnet use distinct wallets |
