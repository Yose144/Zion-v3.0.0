# 03 — Slovník Jádro 108

> *„108 — sanskritské sacred number. 108 jmen Šivy. 108 modliteb v mala. 108 stupňů přechodu mezi vědomími. 108 slov jádra LUMI."*

---

## Proč 108

Číslo **108** je **napříč** **mnoha tradicemi**:

- **Hindu**: 108 jmen Šivy, 108 Upanišad, 108 korálků v *mala* *(modlitebním růženci)*
- **Buddhismus**: 108 *kleshas* *(duchovních nedostatků)* k překonání, 108 *zvuků* v stupě Bodnath
- **Astronomie**: vzdálenost **Země-Slunce** = **108× průměr Slunce**; vzdálenost **Země-Měsíc** = **108× průměr Měsíce** *(přibližně)*
- **Matematika**: 1¹ × 2² × 3³ = 108 *(hluboká kompositní krása)*
- **Joga**: 108 *sun salutations* *(plné kolo)*

**108 slov** je **dost**, aby **postavila** **většinu konverzace**, a **málo**, aby **se to dalo naučit za měsíc**.

## Etymologický přehled — odkud bere LUMI

| Jazyková rodina | % slov | Příklady |
|---|---|---|
| **Indo-evropská — sanskrit/hindi** | ~50 % | mana, dharma, karma, prana, mantra, ... |
| **Polynéská** | ~12 % | aloha, ohana, mauna, moana, pono, kapu, lehua, piko, manu, kupuna, kahuna, wā |
| **Lakota / domorodá Amerika** | ~3 % | mitar, wakan |
| **Romance** | ~10 % | lumi, mela (částečně), per, se, a, o |
| **Bantu / africká** | ~1 % | ubuntu |
| **Východní Asie** | ~5 % | ka, ye, hana *(japonské)* |
| **Univerzální / multi-source** | ~19 % | mi, tu, na, ma, ta, ... |

**Klíčový design**:
- **Sanskrit dominantní** *(50 %)* protože je **historicky** **lingua franca** **sacred / philosophical** vocabulary napříč Asií — od Tibetu po Indonésii
- **Polynéská silně reprezentována** *(12 %)* protože **její vokální struktura** je **přirozeně** **přístupná všem mluvčím**
- **Lakota minimálně** *(3 %)* protože **respektujeme** **ne-otevírání ceremoniálního slovníku** *(jen klíčové vztahové slovo „mitar")*
- **Romance jako glue** *(10 %)* pro **funkční slova**, **která Sanskrit nemá** ve **vhodné formě**
- **Univerzální** *(19 %)* — slova podobná napříč mnoha jazyky *(„mi", „tu", „na")*

## Klíčový princip slovotvorby

S **108 jádrovými slovy** + **agglutinative gramatikou** *(suffixy z kapitoly 02)* lze **vytvořit** **odhad 15 000–30 000** **konstrukovaných slov**.

Příklady kompozit z jádra:

- **lumi-sona** = **světlo-řeč** = LUMI jazyk
- **mitar-ohana** = **příbuzný-rodina** = rozšířená rodinná síť
- **pono-kar** = **rovnováha-konání** = řízení, governance
- **aloha-aina** = **láska-země** = patriotismus, environmentalismus
- **shanti-em** = **mír-místo** = svatyně, klid prostor
- **lumi-mantra** = **světlo-mantra** = QDL tone *(viz kapitola 06)*
- **hana-em** = **květina-místo** = zahrada, park
- **prana-yantra** = **dech-geometrie** = pranayama, dýchací cvičení
- **kala-chakra** = **čas-kolo** = kalendář, cyklus *(direct sanskrit)*
- **bodhi-bhumi** = **probuzení-země** = Bodhgayā, místo osvícení
- **bhū-mela** = **být-krásný** = krása existence
- **na-pono** = **ne-rovnováha** = nespravedlnost, hewa
- **maya-vai** = **iluze-voda** = chamtivost, klam *(„iluzorní voda")*

## Cvičení

1. **Přeloż**: *„Já světlo říkám."* → **Mi lumi sona.**
2. **Přeloż**: *„Tu rodina krásná je."* → **Tu ohana mela.**
3. **Přeloż**: *„Příbuzní rovnováhu dělají."* → **Mi-mitar pono kar.** *(plurál reduplikací)*
4. **Přeloż**: *„Květina v zahradě je."* → **Hana hana-em-a stha.** *(„stha"=stát, lokativ *-a*)*
5. **Přeloż**: *„Učitel pravdu mluví."* → **Guru dharma sona.**
