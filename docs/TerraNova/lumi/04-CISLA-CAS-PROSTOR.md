# 04 — Čísla, Čas, Prostor

> *„Čísla řídí svět. Čas drží vesmír. Prostor mu dává tvar. LUMI tomu všemu říká jedním tahem."*

---

## Čísla 0–10

LUMI používá **dekadickou soustavu** *(10 prstů, univerzální)*. **Slovní zásoba** kombinuje **sanskrit** *(klasický mateřský jazyk indoevropské numerace)* s **domácí jasností**:

| LUMI | Číslo | Etymologie |
|---|---|---|
| **shunya** | 0 | Sanskrit *śūnya* *(prázdnota; **sanskrit dal světu nulu**)* |
| **eka** | 1 | Sanskrit *eka* |
| **dvi** | 2 | Sanskrit *dvi*, latinka *duo*, slovanské *dva* |
| **tri** | 3 | Sanskrit *tri*, latinka *tres*, slovanské *tři* |
| **tetra** | 4 | Řecké *tetra*, sanskrit *catur* — řecké je univerzálnější |
| **panta** | 5 | Řecké *penta*, sanskrit *pañca* |
| **shat** | 6 | Sanskrit *ṣaṭ*, slovanské *šest* |
| **sapta** | 7 | Sanskrit *sapta*, latinka *septem* |
| **ashta** | 8 | Sanskrit *aṣṭa*, latinka *octo* |
| **nava** | 9 | Sanskrit *nava* *(také „nový")*; **homonymum vědomé** |
| **dasha** | 10 | Sanskrit *daśa*, řecké *deka* |

> **Pozn.**: *nava* je **i číslo 9 i přídavné jméno „nový"** *(slovo 060 v slovníku)*. **Nepředpovědné**, ale **kontext rozhodne**. Stejně jako české „pet" *(číslo 5)* a *„pet" (zvíře, anglicismus)*.

## Čísla 11–100

**Stavebnicový systém** *(jako sanskrit)*:

- **11–19**: **dasha + jednotka** → *dasha-eka* (11), *dasha-dvi* (12), *dasha-tri* (13), atd.
- **20**: **dvi-dasha** *(2×10)*
- **21**: **dvi-dasha-eka**
- **30**: **tri-dasha**
- **40**: **tetra-dasha**
- ...
- **100**: **shata** *(sanskrit śata)*

| LUMI | Číslo |
|---|---|
| **dasha-eka** | 11 |
| **dasha-dvi** | 12 |
| **dvi-dasha** | 20 |
| **panta-dasha-eka** | 51 |
| **shata** | 100 |
| **shata-eka** | 101 |
| **shata-eka-dasha** | 110 *(„sto-jedno-deset"…)* — alternativa: **shata + dasha** = 110 přímo |

> **Pravidlo**: **velké jednotky** *(shata, atd.)* **dříve**, **menší později**, jako v indických jazycích. **Sloveso pro výpočet**: **nelze záměnit pořadí** *(„shata-eka" = 101, „eka-shata" = 100, je to jiné!)*.

| **lakh** | 100 000 | Sanskrit/Hindi *lākh* *(používané pan-Indií)* |

V LUMI: **108** = *shata-ashta* *(100+8)*; **144 000** = *eka-shata-tetra-dasha-tetra-sahasra* — **dlouhé!**. **Alternativa**: pro tato *(sacred) čísla* **používáme** **jejich sanskritskou formu**: *aṣṭa-uttara-śata* *(108)*, atd.

## Pořadová čísla

**Ordinální** *(první, druhý, atd.)* se tvoří suffixem **-ma** *(sanskrit „prathama"=první)*:

- **eka-ma** = první
- **dvi-ma** = druhý
- **tri-ma** = třetí
- **shata-ma** = stý

> **Mi eka-ma kar-ta.** = Já první (jsem) udělal/a.

## Roky

**LUMI roky** používají **CE/AD systém** *(common era)*, **ale** **přidávají** **kalpa rámec**:

> Rok 2026 CE = **dvi-sahasra-dvi-dasha-shat** *(2026)* CE-vara
> Pro sacred kontext: rok **„yuga 5126"** *(Kali Yuga začíná 3102 BCE; 3102 + 2024 = 5126)*

LUMI **akceptuje** **plurality** kalendářů — **buddhistický** *(2569 BE)*, **islámský** *(1446 AH)*, **hebrejský** *(5784/5785)*, **mayský** *(5126/5127 dle Long Count)*. **Pro každý** **lze** **zapsat v LUMI**.

## Časová slovesa

Pamatuj z kapitoly 02 — **slovesa beze osoby + s časovým suffixem**:

- **kar** = dělá, dělám *(present)*
- **kar-pa** = udělal/a *(past)*
- **kar-fu** = bude dělat *(future)*
- **kar-ing** = právě teď dělá *(continuous)*
- **kar-ta** = dokončil/a *(perfect)*

### Časové fráze

- **adi-kala-a** = „na začátku času" *(v sacred kontextu = „in the beginning")*
- **anta-kala-a** = „na konci času" *(„at the end of time")*
- **kshana-a** = „v moment" *(„in this instant")*
- **dina-dvi-u** = „od dneška za dva dny" *(„in two days")*
- **kala-pa-a** = „v minulém čase" *(„in the past")*

| LUMI | Směr | Etymologie |
|---|---|---|
| **uttara** | sever | Sanskrit *uttara* |
| **dakshina** | jih | Sanskrit *dakṣiṇa* |
| **pūrva** | východ | Sanskrit *pūrva* *(„první", protože slunce vstává)* |

- **ūrdhva** = nahoru *(sanskrit)*

## Vzdálenosti

Místo přesných metric jednotek *(které jsou kulturně specifické)*, LUMI navrhuje **relativní vzdálenosti**:

| LUMI | Vzdálenost | Použití |
|---|---|---|
| **kshana-gata** | „okamžitá vzdálenost" | hned vedle |
| **mitar-pada** | „příbuzný-krok" | dosáhnutelné chůzí |
| **dina-pada** | „den-krok" | day's walk *(20–30 km)* |
| **moana-gata** | „oceán-cesta" | mezikontinentální |
| **tara-gata** | „hvězda-cesta" | vesmírná |

A pokud potřebuješ **přesnost**: **LUMI akceptuje** **metric units přímo** *(metr, kilometr, atd.)*, jen **přizpůsobí výslovnost** k LUMI fonetickým pravidlům: **metra** *(metr)*, **kilo-metra** *(kilometr)*, atd.

## Cvičení

1. **Přeloż**: *„Tři příbuzní jdou na východ."*
   → **Tri mitar pūrva-e gam.** *(„e" je dativní/směrový suffix)*

2. **Přeloż**: *„Květina kvete každého dne."*
   → **Hana sarva-dina-a kvete...** *(LUMI nemá „kvést" v 108 jádru — potřebujeme **kar** = „dělá": *„Hana sarva-dina-a hana-kar"* = „Květina každého dne květinaří" = kvete)*

3. **Přeloż**: *„V roce 2026 jsem narozený."*
   → **Mi dvi-sahasra-dvi-dasha-shat-a hānau-pa.** *(„hānau" je havajské „narodit se" — můžeme přidat do extended slovníku)*

4. **Přeloż**: *„Jdu na sever ráno."*
   → **Mi prabhat-a uttara-e gam.**
