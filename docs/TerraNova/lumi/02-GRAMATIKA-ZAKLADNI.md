# 02 — Gramatika Základní

> *„Pravidlo bez výjimek je pravidlo. Pravidlo s výjimkou je pověra. LUMI nemá pověry."*

---

## Pět základních principů

1. **Slovosled SOV** *(Subject-Object-Verb)* — jako sanskrit, japonština, hindština, turečtina
2. **Agglutinative morfologie** — afixy se **přidávají** **konzistentně**, **jeden afix = jeden význam**
3. **Žádný gramatický rod** — žádné mužské/ženské/neutrum jako v češtině/němčině
4. **Postpozice místo prepozic** — *„dům-v"* místo *„v-dom"*
5. **Modifikátory před slovem** — *„modrý dům"*, ne *„dům modrý"*

---

## Slovosled

### Základní věta — SOV

> **Mitar pono kar.** = Příbuzný (Subject) rovnováhu (Object) dělá (Verb).
> *„Příbuzný dělá rovnováhu."*

> **Hana lumi sona.** = Květina (S) světlo (O) říká (V).
> *„Květina říká světlo."*

### Modifikátory před slovem

> **Mela hana** = krásná květina *(„krásná" před „květinou")*
> **Pono mitar** = pravdivý/správný příbuzný

### Otázka

LUMI má **jednu** otázkovou částici: **-ka** *(z japonského ka, čínského ma)*. Připojuje se **na konec věty**:

> **Mitar pono kar-ka?** = Dělá příbuzný rovnováhu?

### Negace

LUMI má **jednu** negační částici: **na-** *(z univerzálního „ne/no/nay")*. Předchází **sloveso**:

> **Mitar pono na-kar.** = Příbuzný **ne**dělá rovnováhu.

---

## Podstatná jména

### Bez gramatického rodu

V LUMI **neexistuje** **mužský/ženský/neutrum**. **„Mitar"** je **„příbuzný"** *(person)* bez ohledu na gender. Pro **specifikaci** **lze přidat** afix:

- **mitar-na** = příbuzný-žena *(matka, sestra, dcera, teta — záleží na kontextu)*
- **mitar-ar** = příbuzný-muž *(otec, bratr, syn, strýc)*
- **mitar** *(default)* = **gender-neutral**, **používá se nejčastěji**

> **„-na"** pochází z **hindského „nari"** *(žena)* + **lakotského „wíŋ"** *(žena, zkráceno)*
> **„-ar"** z **arabského „rajl"** *(muž)* + **sanskritského „nara"** *(muž)*

### Plurál

**Plurál** se tvoří **opakováním** první slabiky **(reduplication)** — jako v **havajštině** a **mnoha austronéských jazycích**:

- **mitar** *(příbuzný)* → **mi-mitar** *(příbuzní)*
- **hana** *(květina)* → **ha-hana** *(květiny)*
- **lumi** *(světlo)* → **lu-lumi** *(světla, mnoho světel)*

**Pokud je z kontextu jasné**, že se mluví o množství *(„tři květiny", „mnoho lidí")*, **plurál se vynechává**:

> **Tre hana** = tři květiny *(plurál implicitní v čísle)*
> **Mucho mitar** = mnozí příbuzní *(„mucho" z portugalštiny/španělštiny)*

### Pády

LUMI má **6 pádů** vyjádřených **postpozicemi** *(suffixy)*:

| Pád | Suffix | Použití | Český ekvivalent |
|---|---|---|---|
| Nominative | (žádný) | Subject | „kdo / co" |
| Accusative | **-o** | Direct object | „koho / co" |
| Genitive | **-i** | Possession | „čeho / koho" |
| Dative | **-e** | Indirect object | „komu / čemu" |
| Locative | **-a** | Place | „kde / v čem" |
| Ablative | **-u** | From | „odkud / od čeho" |

Příklady:

- **mitar** = příbuzný *(nominativ)*
- **mitar-o** = příbuzného *(akuzativ — koho mám rád)*
- **mitar-i** = příbuzného *(genitiv — kniha příbuzného)*
- **mitar-e** = příbuznému *(dativ — dávám příbuznému)*
- **mitar-a** = u příbuzného *(lokativ — jsem u příbuzného)*
- **mitar-u** = od příbuzného *(ablativ — jdu od příbuzného)*

> **Mnemotechnika**: O-I-E-A-U → česky **„nahoru přes hlubinu"** = **5 vokálů ve specifickém pořadí**, pomáhá si zapamatovat.

## Slovesa

### Žádné nepravidelné formy

**Všechna slovesa** se časují **stejně**. **Jediná výjimka**: **„être/to be"**, které **v LUMI vůbec neexistuje** *(jako v ruštině v přítomném čase, jako v japonštině v běžné řeči)*.

> **Mi mela.** = Já krásný/á. *(„Jsem krásný/á.")*
> **Hana lumi.** = Květina světlo. *(„Květina je světlo." — copula pro identitu se vynechává.)*

### Tense systém

LUMI má **4 časy**:

| Čas | Suffix | Příklad |
|---|---|---|
| **Přítomný** | (žádný) | **kar** = dělá / dělám |
| **Minulý** | **-pa** | **kar-pa** = dělal/a *(„pa" z portugalského „passou")* |
| **Budoucí** | **-fu** | **kar-fu** = bude dělat *(„fu" z anglického „future")* |
| **Probíhající (continuous)** | **-ing** | **kar-ing** = právě teď dělá *(„ing" z angličtiny)* |

### Aspekt — dokončenost

Pro **dokončené akce** přidej **-ta**:

- **kar** = dělá *(present, neukončeno)*
- **kar-ta** = udělal *(perfect, dokončeno)*
- **kar-pa-ta** = byl udělaný *(past perfect, dokončeno v minulosti)*

### Osoba

LUMI **NESPOJUJE osobu se slovesem**. Místo toho používá **zájmena**:

| Osoba | Zájmeno |
|---|---|
| Já | **mi** |
| Ty | **tu** |
| On/Ona/Ono | **se** |
| My | **mi-mi** *(reduplication)* |
| Vy | **tu-tu** |
| Oni | **se-se** |

> **Mi pono kar.** = Já rovnováhu dělám.
> **Tu lumi sona.** = Ty světlo mluvíš.
> **Mi-mi ohana mela.** = My rodinu milujeme. *(mela = „milovat", odvozeno z „mela"=krásný)*

---

## Přídavná jména

### Modifikátor před podstatným jménem

> **Mela hana** = krásná květina
> **Pono mitar** = pravdivý příbuzný
> **Lumi sona** = světelná řeč

### Stupňování

Tvořeno **suffixy**:

| Stupeň | Suffix | Příklad |
|---|---|---|
| Pozitiv | (žádný) | **mela** = krásný/á |
| Komparativ | **-ar** | **mela-ar** = krásnější *(„ar" z latinského „magis-ar/io")* |
| Superlativ | **-os** | **mela-os** = nejkrásnější *(„os" z portugalsko-italského „o-sissimo")* |

> **Hana mela.** = Květina krásná. *(„Květina je krásná.")*
> **Hana mela-ar mitar-u.** = Květina krásnější (než) příbuzný-od. *(„Květina je krásnější než příbuzný.")* — *„u"* je ablativní *„than"*.
> **Hana mela-os.** = Květina nejkrásnější.

---

## Příslovce

Z přídavných jmen **suffixem** **-li** *(„light"-like)*:

- **mela** = krásný → **mela-li** = krásně
- **pono** = pravdivý → **pono-li** = pravdivě / správně
- **lumi** = světlý → **lumi-li** = jasně, světle

> **Mitar pono-li sona.** = Příbuzný pravdivě mluví.

---

## Spojky

| LUMI | Význam | Pochází z |
|---|---|---|
| **a** | a, i | univerzální *(angličtina, švédština, latina)* |
| **o** | nebo | univerzální *(italština, latina)* |
| **ma** | ale | sanskrit *(„ma" = ne)*, polynéské *(„ma"=ale)* |
| **ka** | (otázková) | japonština, čínština |
| **se** | jestliže | latina *(„si"), portugalština („se")* |
| **per** | protože | latina *(„per")*, anglické *(„per")* |
| **ye** | tedy | sanskrit *(„yathā"="tak")* |

Příklady:

> **Mi sona a tu sona.** = Já mluvím a ty mluvíš.
> **Hana mela ma na-pono.** = Květina krásná, ale ne pravdivá.
> **Se tu kar, mi kar-fu.** = Pokud ty děláš, já udělám.

---

## Slovotvorba (kompozity)

LUMI **kombinuje slova** k tvorbě nových:

### Spojení dvou kořenů

- **lumi + sona** = **lumisona** *(světlo-řeč = „světelný jazyk")*
- **mitar + ohana** = **mitarohana** *(příbuzný-rodina = „rozšířená rodina")*
- **pono + kar** = **ponokar** *(rovnováha-konání = „řízení")*

**Pravidlo**: **prvním kořenem** modifikuje **druhý**. *„Lumisona"* je **typ řeči**, ne **typ světla**.

### Derivace přes suffixy

Klíčové **derivační suffixy**:

| Suffix | Význam | Příklad |
|---|---|---|
| **-er** | „kdo dělá X" | **kar-er** = dělající, dělník |
| **-em** | „místo X" | **lumi-em** = místo světla, lampa |
| **-an** | „abstraktní X" | **pono-an** = pravdivost, balance jako pojem |
| **-ek** | „malý X" | **hana-ek** = kvítek |
| **-on** | „velký X" | **hana-on** = velká květina, strom |

> **Mitar-er** = ten, kdo je rodina-člen
> **Sona-em** = místo řeči = scéna, fórum
> **Aloha-an** = abstraktní láska/přítomnost

## Shrnutí gramatiky

**Pokud si pamatuješ tohle, znáš LUMI gramatiku**:

```
SLOVOSLED:        S - O - V       (subject - object - verb)
PÁDY:             -o -i -e -a -u  (acc, gen, dat, loc, abl)
ČAS:              -pa -fu -ing    (past, future, continuous)
ASPEKT:           -ta             (perfect)
PLURÁL:           reduplication   (mitar → mi-mitar)
NEGACE:           na-             (na-kar = nedělá)
OTÁZKA:           -ka             (kar-ka? = dělá?)
KOMPARATIV:       -ar             (mela-ar = krásnější)
SUPERLATIV:       -os             (mela-os = nejkrásnější)
PŘÍSLOVCE:        -li             (mela-li = krásně)
KOMPOZITA:        kořen + kořen   (lumi + sona = lumisona)
```

**11 pravidel**. **Žádné výjimky**. **Hotovo**.

> *„Tu pravidla zna-ta. Tu LUMI sona-fu. Pravidla znáš. Budeš mluvit LUMI."* 🌟
