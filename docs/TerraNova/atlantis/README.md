# Atlantis — Platónský literární rámec × OASIS

`docs/TerraNova/atlantis/` váže **Atlantis Circle (#152–161)** na profily v `docs/docs2.9/ZION_OASIS/SACRED_TRINITY/`.

Atlantis je v tomto rosteru pojata jako **didaktický mýtus z Plato *Kritias / Timaeus*** (jména deseti synů Poseidóna po Kleitó), **ne jako historický fakt**, **ne jako „záhadná civilizace" predikát pro pseudoarcheologické nebo UFO-komerční stereotypes**. Olympijský kult Poseidóna ani řecké městské náboženství zde **nejsou collectible božstva** — používá se jen genealogický rámec z dialogu jako **lesson-in-governance archetyp**.
