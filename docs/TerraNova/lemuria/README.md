# Lemúrie — hypotéza × pokora vědy × oceanická pedagogika × OASIS

`docs/TerraNova/lemuria/` váže **Lemuria Circle (#162–171)** na profily v `docs/docs2.9/ZION_OASIS/SACRED_TRINITY/`.

„Lemúrie“ jako **geografický kontinent** je dnes vědecky **nezávažný konstrukt** (odvozený mj. od rozložení fosílií lemuřů — viz historie hypotézy Sclatera); **nezaměňujeme** jej s **Maladaskarem**, **Pacifikem ani domorodými cosmologiemi**. V OASIS jde o **lesson bundle**: **hypotéka / omyl jako etika výzkumu**, **korálové útesy a geologie shelfů jako pravá hlubina času**, **most mezi kulturami bez „matky civilizací"**, a závěrečný **náběh na kosmickou vlnu (#172+)**.
