## Proč lite

Plná **tibetská buddhistická tradice** je **enormní**:
- **2 500 let** **kumulovaného učení** *(Buddha → Nāgārjuna → Padmasambhava → Atiśa → Tsongkhapa → současnost)*
- **Tisíce sútter, tantér, komentářů**
- **Čtyři hlavní školy** *(Nyingma, Kagyü, Sakya, Gelug)* + **Bön** *(pre-buddhistická)*
- **Žijící tradice** s **mnoha kvalifikovanými učiteli** v exilu i v Tibetu

**Jeden cizinec** *(autor této knihovny)* **nemá nárok** **adekvátně** **reprezentovat** **takový rozsah**. **Místo toho** **píšu lite koncept**, **abych otevřel prostor**, **a delegoval na ty**, **kdo** **mají autoritu mluvit** *(Tibetští učitelé, akademici buddhismu, dlouholetí praktici)*.
