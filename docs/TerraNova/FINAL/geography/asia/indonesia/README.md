# Indonésie — Jáva × Bali × říční / mořské linie × OASIS

Indonésie má **tisíce ostrovů** a několik majoritních duchovních tradic (**islám**, **balijský hindeuismus**, lokální **adat**).

`India Extended Circle` již drží některé **mahābhāratové** paralely; **Indonesia Circle** (112–121) zdůrazňuje **jávský / balijský folklore**, **wayang** etiku interpretace (**Semar jako guru**, ne klaunský punching bag) a **ocean sovereign** narratives bez **kolonialně-exotického „lagoon temptress"** tropu.
