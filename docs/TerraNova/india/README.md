## O čem je tato knihovna

`docs/TerraNova/india/` propojuje **živou hinduistickou a širší indic tradici** s rozšířeným rosterem **ZION OASIS** — **`India Extended Circle` (avatari 82–91)** — tam, kde už v **Sacred Trinity** existují Rāma, Kṛṣṇa, Mahābhāratovské linie aj., ale **chyběla výslovná Trimūrtí–Śakti osu** (Mahādeva-Parvatī-Ganeša) a některé **šíře rozšířené** védske / purāṇovské archetypy (Sūrya, Indra, Gaṅgā).

Nejde o učebnici Sanskritu ani o náhradu **iniciační tantrie** — OASIS zůstává **veřejně etickým** lore rámcem.

## Etika (stručně — detail v koncept souboru)

1. **Konzultovat** výtvarnou a narativní reprezentaci s hinduisty (Indie i diaspora); nepřeskakovat jejich zpětnou vazbu kvůli rychlému NFT release.
2. **Žádné zesměšňování** snānám, śivarātry, navarātī atd.; žádné **lootování** posvátných předmětů (jako u Pacific / First Nations pravidel).
3. **Kālī (#87)** — rámek **svatá Matka-aspekt**, časová transformace lpění — **zakázány** orientalizované „monster girl" kýče a hororové turistika zóny.
4. **Védské texty** — citovat přes akademické zdroje a veřejné překlady, ne přes meme redukci.
5. **Viṣṇu linie**: Kṛṣṇa, Rāma, Kalkī, Hari atd. **už v rosteru** — India Circle **neduplikuje**, doplňuje **Śiu a Śaktī** a klasický **Śrī Lakṣmī** jako **samostatný (#85)** vůči kompozitní **[43] Sri Anagha Lakshmi**.
