# Austrálie — First Nations stewardship × TerraNova × OASIS

Tato složka je **literární a etický rám** pro **Australia Circle (122–131)**.

**⚠️ Povinně:** konsultovat s příslušnými **Aboriginal / Torres Strait Islander** komunitními strukturami před jakýmkoli **NFT mintem**, **VO castingem**, nebo použitím **konkrétních Dreaming příběhů** spojených s **omezeným** sdílením.

Postavy používají **kompozitní / veřejně vyučované** rámy kde je to nutné („Seven Sisters astronomical songlines", „Emu in the Sky") **s explicitním uznáním multiplicity národů**.

**Žádné Wandjina** imagery jako kosmetické skiny bez právně validní licence od příslušných držitelů Kimberley regionu.
