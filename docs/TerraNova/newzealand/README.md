# Aotearoa New Zealand — Te Ao Māori × OASIS

Složka `docs/TerraNova/newzealand/` dokumentuje **Aotearoa Circle (132–141)** — **ātua** a navigator archetyp výslovně v **tikanga Māori** rámu etiky.

## Křížové odkazy

- **[71 Māui]** — pan-polynéský trickster už v rosteru jako **Pacifik** avatar; Māori Māui používejte jako **lore cross-ref**, ne povinně duplicitní číslo. Zde **nezahrnut** záměrně jako nové ID.
- **[66 Kanaloa / 135 Tangaroa]** — oceánická homology; Māori arcs musí používat **vlastní Māori pojmenování a protokoly** (kai moana etiquette, rahui parallels in game ecology).
