# Terra Nova: Kód Vědomí
*(Gemini Edice — Literární a kreativní rozpracování kánonu ZION)*

---

## 🔮 O této edici

Tato složka obsahuje alternativní, literárně bohatší zpracování kánonu **Terra Nova**. Vychází z původních myšlenek (architektura L1-L6, Zlatý kompas, propojení Véd a kvantové fyziky, Issobella), ale zasazuje je do širšího narativního rámce.

Najdete zde více "vesmírných příběhů", deníkových záznamů Guardians a pohlcující atmosféru budoucnosti, která nevznikla z chaosu, ale z jednoho čistého, nezměnitelného kódu — **Kódu Vědomí**.
