# Staroegyptský (faraonský) kruh — TerraNova + OASIS **#192–201**

Tato složka doplňuje ZION OASIS o **klasický egyptský pantheon a kosmologii** v literárně-archeologickém rámci — **ne** jako výzvu k loupeži muzeí ani jako „tajnou iniciaci“ přes NFT.

## Návaznost v rosteru

- **Core** už obsahuje **Isis-Enamataru [#06]** (Luxor / božská ženskost v širší linii).
- **Africa Circle** má **Ausar–Osiris [#149]** a **Maʿät [#150]** v kemetsko-diaspózní etice.
- Tento kruh **#192–201** přidává **další faraonské archetypy** (Ré, Hor, Thovt, Hathor, Sachmet, Ptah, Anup, Amon, Geb, Nut) jako **DAO / řetězové metafory** s oddělenými questy od výše uvedených slotů.
