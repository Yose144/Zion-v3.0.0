# 01 — Slovo Hunab Ku

> *„Hunab Ku. Jediný Bůh. Velký Tvořící Princip, který je neviditelný a nemůže být zobrazen. Z něj vyzařují všechna jména, všechny formy, všechny síly."*
> — Mayská kosmologie
