## 0. Podmínka vpředu (nepřeskakovat)

```bash
# 1. Nikdo nebuildí a nikdo necommituje
ps aux | grep -E "next build|npm run build|tsc -p" | grep -v grep          # musí být prázdné
git status --short | grep -E "^\s*M" | head                                # vědět, čí WIP v tree je
date +%H:%M:%S; git log -1 --format='%ad %s' --date=format:%H:%M:%S        # poslední commit
# 2. Poslední změna souborů je starší než ~10 min
find . -path ./.git -prune -o -newermt "-10 minutes" -type f -name "*.ts*" -print | grep -v node_modules | head
```

Když cokoli z toho nesedí, **počkej**. Okno potřebuje ~10 minut klidu.

### 2b. ⚠️ `apps/*/node_modules` NEMAZAT

První pokus tohle udělal a shodil buildy. `npm ci` tam **legitimně** instaluje to, co nejde hoistovat:

| Co | Kde | Proč |
|---|---|---|
| `@babylonjs/*` | `apps/OasisWeb/node_modules` | v locku jsou zanořené, root je nemá |
| `tailwindcss@3.4.19` | root (devDep) | 3 appky jsou na v3, 3 na v4 — v3 musí být v rootu, v4 se zanoří |
| `postcss`/`autoprefixer` (pinned) | per-app | zamražené verze z migrace |

Po smazání app stromů OasisWeb nenašel `@babylonjs/core` a pool-ui vzal root `tailwindcss@4` → „PostCSS plugin has moved". **Stačí `npm ci` a nic nemazat.**

### 2c. root `tailwindcss@3` je součást migrace

`/package.json` má `devDependencies.tailwindcss: "3.4.19"`, aby tři v3 appky (`pool-ui`, `IntroPage`, `MarketPlace`) našly plugin tam, kam se dívají jejich `postcss.config.*`. Bez toho PostCSS v Turbopacku resolvuje z workspace rootu a dostane v4 → build spadne. **Tuhle devDependency neodstraňovat**, dokud se všechny appky nesjednotí na jednu major verzi.

### 2d. Po změně konfigurace smazat `.next`

Turbopack drží transform cache. Po opravě tailwindu build **pořád** hlásil starou chybu, dokud jsem nesmazal `apps/pool-ui/.next`. Při ladění vždy `rm -rf apps/<app>/.next`.

## 5. Rollback

```bash
# celý merge
git reset --hard ORIG_HEAD          # nebo konkrétní commit před mergem
rm -rf node_modules
for a in pool-ui IntroPage MarketPlace nirvana OasisWeb website-v2.9 shared zion-wallet-sdk; do
  (cd "apps/$a" && npm install)     # obnoví per-app stromy ze starých lockfilů (ty merge vrátí)
done
```

Pozor: staré per-app `package-lock.json` se mergem **smažou**, ale `git reset --hard` je vrátí — proto rollback funguje jen přes gitu, ne ručním mazáním souborů.
