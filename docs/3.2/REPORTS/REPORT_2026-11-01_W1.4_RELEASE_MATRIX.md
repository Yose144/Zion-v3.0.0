## 2. Jak se to stavělo (čistý worktree, sdílená cache)

```bash
SHA=$(git rev-parse --short=9 HEAD)
git worktree add --detach /tmp/zion-rc-$SHA HEAD          # čistý strom, tree_state: clean
cd /tmp/zion-rc-$SHA
CARGO_TARGET_DIR=~/Projects/2.9.6/V31/target \
  bash scripts/ops/build-release-artifacts.sh \
    --version v3.2.0-rc-w1.4 --from-commit HEAD \
    --target aarch64-apple-darwin \
    --variant "gpu-metal:auxpow,gpu-metal,native-hashers,native-kheavyhash,native-blake3-algo,native-verushash" \
    --packages "zion-miner zion-cli"
```

`CARGO_TARGET_DIR` je nová podpora v builderu — bez ní by čistý worktree musel duplikovat
~11 GB `target/` (na dev Macu zbývá ~12 GB).

## 3. Tři chyby builderu, které to odhalilo (opravené)

| # | Problém | Dopad | Fix |
|---|---|---|---|
| 1 | `${arr[@]}` na **prázdném** poli + `set -u` (bash 3.2 na macOS) | build spadl hned na `jobs_flag[@]: unbound variable` | `${arr[@]+"${arr[@]}"}` v native i container cestě |
| 2 | `[ -f "$f" ] && cp "$f" …` jako poslední příkaz smyčky | se `set -e` vrátí 1 → `build_one` = FAIL, **i když cargo doběhl** `Finished release profile` | explicitní `if [ -f … ]; then cp …; fi` |
| 3 | kopírování binárek z `$V31/target`, i když je nastaven `CARGO_TARGET_DIR` | čistý worktree by neměl odkud kopírovat | `tdir="${CARGO_TARGET_DIR:-$V31/target}"` |

Bez opravy #2 se binárky přeložily (8m55s a 10m18s), ale skript je zahodil jako neúspěch —
to je přesně ten druh tiché chyby, který u release matice bolí.

## 4. Co ještě chybí

1. **Linux z téhož commitu** — současné linux tarbally pinují `aa6599cce` (31. 10.). Pro jednotnou
   matici je potřeba přebuild z `8c3833a7e` s **pinovanou glibc** — buď
   `--container rust:1.95-slim-bullseye` (glibc 2.31), nebo na EDGE. Build na dev Macu (glibc 2.43
   přes cross) by dal artefakt nepoužitelný na starších distrech.
2. **Windows + OpenCL** — `-lOpenCL` na mingw chybí (ICD loader se nedodává); proto je Windows
   artefakt **CPU-only**. Kdo chce GPU mining na Windows, staví z feature matrix s `gpu-opencl`
   proti nainstalovanému OpenCL SDK.
3. **macOS x86_64 (Intel)** — target `x86_64-apple-darwin` je nainstalovaný, build nezkoušen
   (matice ho zmiňuje s `gpu-opencl`). Není blokující pro 3-platformový požadavek.
