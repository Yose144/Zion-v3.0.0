# REPORT 2026-10-31 — W3.2 Public scan gate

> **Stav:** Rozšířeno (dokumentace + jasné označení)  
> **Soubor:** `scripts/ops/public-export.sh`

## Současný stav
`public-export.sh` už má **fail-closed secret scan**:
- `scan` krok kontroluje `PRIVATE KEY`, `mnemonic/seed phrase`, assignment vzory s neprázdnou quoted hodnotou, `sk_live_`, `AKIA...`, `0x{64}`
- Používá allowlist `scripts/ops/public-scan-allowlist.txt`
- `push` vždy volá `export + scan` jako **gate** (nelze obejít)
- Binary/large guard

## Rozšíření (dokumentační + jasné)
- Přidáno explicitní označení **REQUIRED GATE** do hlavičky
- Zdůrazněno: `scan` musí projít před každým push do veřejného repa
- Fail-closed princip zachován

## Doporučení
Scan je už povinný v `push` workflow. Pro CI/release je doporučeno volat `./scripts/ops/public-export.sh scan` samostatně.
