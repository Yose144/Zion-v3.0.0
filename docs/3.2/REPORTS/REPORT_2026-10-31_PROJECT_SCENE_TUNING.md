## Deployment procedure

Both deploy wrappers accept `--artifact-dir` for a tested standalone application containing `server.js`, `.next/BUILD_ID`, `.next/static` and traced dependencies. `scripts/ops/deploy-next-artifact.sh` transfers it into a sibling staging directory, preserves runtime environment files, switches directories and retains the previous application. Startup and public root health failures restore the previous application automatically.

The website is deployed to EDGE2 first, Nirvana to EDGE second. Post-deploy verification must check all 24 project routes, static assets and actual WebGL startup. Release worktrees and temporary preview servers are removed after acceptance; rollback backups and one local evidence set are retained.
