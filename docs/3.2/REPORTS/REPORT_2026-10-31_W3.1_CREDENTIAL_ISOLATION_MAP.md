# REPORT 2026-10-31 — W3.1 P0-3 credential isolation (map + návrh)

> **Status:** Návrh (read-only), **bez rotace secretů**  
> **Problém:** `/etc/zion/edge-environment.sh` je sdílený pro všechny V31 služby → každá vidí cizí credentials (P0-3)

## Současný stav
- **EDGE:** `zion-v31-pool.service` má `EnvironmentFile=/etc/zion/edge-environment.sh`
- **EDGE2:** služby mají svůj model (standby pool má vlastní `pool-standby.env`), ale node/multichain/dao často sdílejí env
- **Rozsah:** ~58 `export` v edge-environment.sh, velká část je globální/sdílená

## Návrh per-service subsetů (mapa)
| Služba | Potřebné klíče (minimální subset) | Poznámka |
|---|---|---|
| **zion-v31-pool** | `ZION_POOL_*`, `ZION_NODE_RPC_ADDR`, `ZION_PPLNS_*`, `ZION_VARDIFF_*`, `ZION_AUXPOW_*` | AuxPoW/wallety pro external streams |
| **zion-v31-node** | `ZION_NODE_*`, `ZION_RPC_*`, `ZION_P2P_*`, genesis/network | L1 consensus kritické |
| **zion-v31-multichain/warpd** | `WARP_*`, `ZION_BRIDGE_*`, `RPC_*` chain endpoints | EVM/non-EVM, klíče validatorů |
| **zion-v31-dao** | `DAO_*`, `ZION_DAO_*` | Governance |
| **zion-v31-ai-native/maestro** | `LLM_*`, `RAG_*`, model config | oddělit od money-path |
| **monitoring/probes** | `ZION_TELEGRAM_*`, `PROM_*` | alerty oddělené |

## Doporučený postup
1. **Inventarizace** – pro každou službu zjistit skutečně používané proměnné (grep v binárce/systemd)
2. **Vytvořit subset soubory** – `/etc/zion/env/<service>.env` s 600 perms, `chown zion:zion` kde vhodné
3. **Přepnout unitě** – `EnvironmentFile=` na subset, odstranit z globálního
4. **Rotace** – až po ověření (mimo tento pass), zvláště klíče validatorů/WARP
5. **Validace** – restart služeb, health checky

**Poznámka:** Toto je **návrh**, žádné změny nasazeny. Rotace secretů vyžaduje 👤 souhlas + air-gapped postup.
