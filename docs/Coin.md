Nejzajímavější pro CPU
1. Monero (XMR) – RandomX
✔ stále nejvíce doporučovaný coin pro CPU mining
✔ algoritmus navržený pro CPU a resistentní vůči klasickému ASICu
✔ i slabší PC má šanci něco vytěžit
💡 Výnos je ale malý – pár korun až desítky Kč denně (záleží na CPU a ceně elektřiny).
2. VerusCoin (VRSC) – VerusHash 2.2
✔ CPU friendly
✔ silně ASIC-resistentní
✔ někdy vyšší výnos než Monero na stejném CPU
💡 Dobrý i pro starší procesory.
3. Raptoreum (RTM) – GhostRider
✔ algoritmus navržený pro výkon více jader
✔ CPU je konkurenceschopné GPU u tohoto projektu
💡 Často uváděný jako alternativní možnost, i když výnosy variují.
4. Oxen (dříve Loki) – modifikovaný RandomX
✔ podobné Moneru, ale menší síť → potenciálně lepší šance vytěžit blok
✔ CPU použitelný na mining i provoz servisních uzlů
💡 technicky orientovaní těžaři to zmiňují jako solidní volbu.
5. Aeon (AEON) – light RandomX fork
✔ lehčí verze Monero-algoritmu
✔ nižší nároky → vhodné i pro starší/low-power CPU
💡 celkově menší odměny, ale stabilní a nízké náklady.
