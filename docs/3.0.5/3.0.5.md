## Co je 3.0.5 (vs 3.0.4)

3.0.5 je **"All Green" upgrade** nad 3.0.4 hard reset:

1. **Protocol bump** 3.0.3 → 3.0.5 (`V3/L1/core/src/lib.rs:47`)
2. **Docs reconcile** — falešné commity, staré IP, aktivační výšky opraveny
3. **L2/L3 operationalizace** — bridge, dao, warp, atomic-swap všechny BUILT + deploynuty
4. **Web repair** — Docker restart, 377 MB image (bylo 2.57 GB)
5. **Watchdog timer** — 2 min interval, auto-restart
6. **E2E memo testy** — 3 account-model TXs s memos potvrzeny v bloku 752
7. **Memory leak fix** — block retention capped at 1000, bounded channels

### Security hardening (2026-07-10)

- **AppArmor** — profil `/etc/apparmor.d/usr.local.bin.zion-node`, complain mode
- **systemd User=zion** — system user uid=999 **not created**, service files still use `User=root`, config in `/root/zion-2.9.6-main/edge-deploy/config/`
- **Key rotation F4.x** — owner air-gapped, pool payout SK + escrow SK aplikovány, EVM/guardian SKs na flash disku
- **Stale IP cleanup** — 69 souborů, commit `8d55287f9`
- **BFG git history scrub** — `PREMINE_WALLETS_BACKUP.json` odstraněn z historie
- **Tailscale** — odstraněn (decommissioned), hardcoded seed peers
