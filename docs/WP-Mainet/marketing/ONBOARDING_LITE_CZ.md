# ZION — Onboarding Lite (CZ)

## Co je ZION za 30 vteřin

ZION je vlastní Layer 1 blockchain v Rustu. Proof-of-Work, ~60s bloky, 144 miliard ZION, žádný ICO. Každý blok rozděluje odměnu 89/5/5/1 mezi těžaře, humanitární fond, budoucnost a spálení. Má vlastní minera, pool, peněženku, bridge, DAO a herní svět Oasis.

## Tři rychlé cesty

### 1. Dívej se (30 sekund)
- Otevři https://zionterranova.com — živá síť, nový blok každou minutu.
- Prolistuj kód: https://github.com/Zion-TerraNova/v3-Mainnet (MIT licence).

### 2. Hraj (5 minut)
- Vejdi do Oasis: https://oasis.zionterranova.com
- Vyber avatara, projdi úvod, přihlaš se peněženkou.

### 3. Těž / stavěj (15 minut)
```bash
git clone https://github.com/Zion-TerraNova/v3-Mainnet.git
cd v3-Mainnet/V31
cargo build --release
./target/release/zion --help
```

Veřejný pool: `pool.zionterranova.com:8444`

## Klíčová čísla

- Hard cap: 144 000 000 000 ZION
- Blok: ~60 s
- Rozdělení: 89 % těžař, 5 % humanitární, 5 % budoucnost, 1 % burn
- Public RPC: `rpc.zionterranova.com:8443`
- Pool: `pool.zionterranova.com:8444`
- Licence: MIT
- Status: Mainnet Beta

## Co ZION neslibuje
- Není investiční doporučení.
- Není náboženské tvrzení.
- Není hotová AAA hra — Oasis je živý preview.
- Ztracený klíč = ztracené ZION.
