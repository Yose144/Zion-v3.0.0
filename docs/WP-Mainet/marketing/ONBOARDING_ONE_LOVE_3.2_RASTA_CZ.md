# HEAR THE DRUM, MINER

## Proč těžit ZION na začátku?

Bredda, sůl se nerozpouští až po hostině. Kořeny se nesází až ve chvíli,
kdy strom už padá. Když je síť mladá, nezískáváš „garantovaný výnos“ —
to ti nikdo poctivě slíbit nemůže. Získáváš ale možnost **učit se,
pomáhat zabezpečit síť a vzít do ruky nástroje dřív, než se z malé řeky
stane široké moře.**

## Five reasons to mine the roots

### 1. První dekáda nese nejvyšší naplánovanou blokovou odměnu

Protokol má pevně zapsanou odměnu **5 400,067 ZION za blok** pro první
dekádu (výšky 1 až 5 256 000). Potom se bloková odměna každou dekádu
snižuje o 20 %. To není cenová predikce — je to otevřeně auditovatelná
emisní křivka v kódu.

### 2. 89 % každé subsidy patří těžařům

Z každé blokové subsidy je **89 % vyhrazeno minerům**. Pool rozděluje
odměnu proporcionálně podle přijaté práce v PPLNS okně. Dalších 5 % jde
na humanitární fond, 5 % na Issobellu a 1 % se nemintuje / spaluje.

Tvoje hashe tak nekrmí jen tvůj worker. Pomáhají držet síť otevřenou a
současně nesou její společenský rytmus.

### 3. Učíš se na živé síti, ne na powerpointu Babylonu

Pool přijímá share, node produkuje bloky, payout confirmation sweep běží
a veřejný stratum je otevřený na `62.171.141.136:8444`. Ranný těžař se
učí wallet, rig, monitoring, worker naming a bezpečnost dřív, než se
z toho stane davový sport.

### 4. Jeden rig, tři proudy

Oficiální `zion-miner` umí **Trinity**:

| Proud | Co dělá | Stav |
|---|---|---|
| Stream 1 | Těží ZION přes Ekam Deeksha v3.2 | živý |
| Stream 2 | Volitelný GPU AuxPoW proud (např. ZANO) | živý, závislý na upstream poolu |
| Stream 3 | Volitelný CPU AuxPoW proud (např. VRSC) | živý, závislý na upstream poolu |

Trinity není slib vyššího zisku. Je to technická možnost využít GPU a CPU
v jednom mineru, zatímco podmínky externích poolů, jejich dostupnost,
difficulty a aktuální ceny se stále mění.

### 5. Tvůj feedback má váhu

Mladá síť potřebuje víc než hashrate. Potřebuje lidi, kteří dokážou říct:
„Tady se miner chová divně. Tady chci lepší TUI. Tady je můj GPU driver.
Tady se share ztrácí.“ První miners nejsou jen uživatelé. Jsou první
stavitelé mostu.

> **Real talk — žádné pohádky o lambu:**
>
> Skutečná odměna závisí na tvém hashratu, podílu vůči síti, difficulty,
> počtu přijatých share, PPLNS okně, dostupnosti poolu, provozních nákladech
> a tržní ceně ZION. Nic z tohoto dokumentu není investiční doporučení ani
> záruka výnosu.

# ROOTS, RIDDEM, REALITY

## Co je ZION v jednom nádechu?

ZION je open-source Layer 1 blockchain v Rustu. Každý blok je důkaz práce,
ne důkaz kontaktů. Každá zásadní konstanta se dá zkontrolovat v kódu.
A každý, kdo přijde s respektem, může být pozorovatel, hráč, miner nebo
stavitel — nikdo z nich nestojí nad druhým.

| Riddim | Ověřitelná realita |
|---|---|
| **Roots** | Ekam Deeksha v3.2: 512 KiB scratchpad, 2 AES passy, 128 random reads, Keccak-256 final hash |
| **One Love economics** | 89 % miner / 5 % humanitarian / 5 % Issobella / 1 % burn slot |
| **No closed door** | Kód je veřejný pod MIT; veřejné ICO / presale není součástí projektu; genesis alokace je dokumentovaná, ne tajná |
| **Live water** | V31 node, pool, miner, multichain, DAO, OASIS, dashboard, web a marketplace běží na Edge produkci |
| **The horizon** | Mainnet Stable 3.2 potřebuje ještě 30denní run, reálné GPU E2E, security review, chaos testy a další ověřitelné brány |

# PICK YOUR PATH

## Path 1 — Miner: „Mám rig. Chci ho zapojit do riddimu."

1. Vytvoř si **vlastní** ZION wallet adresu. Mnemonik a privátní klíče nikdy nikomu neposílej.
2. Postav nebo stáhni `zion-miner` pro svůj systém.
3. Připoj se k veřejnému poolu `62.171.141.136:8444`.
4. Začni s konzervativním nastavením, sleduj accepted/rejected share a teploty.
5. Až pak objevuj GPU backend, TUI a Trinity proudy.

Příklad minimálního lokálního V31 běhu:

```bash
cd V31
cargo build --release --bin zion-miner
./target/release/zion-miner \
  --pool 62.171.141.136:8444 \
  --wallet zion1...tvoje_adresa \
  --worker roots-rig-01 \
  --threads 4
```

Před produkčním miningem si vždy ověř aktuální release instrukce, podporu
tvého hardware a stav poolu. Přijatý share není automaticky okamžitá
výplata; pool používá PPLNS a on-chain potvrzení výplat.
