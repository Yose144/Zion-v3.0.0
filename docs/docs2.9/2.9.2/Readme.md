### Option 1: Docker Production (Recommended)

```bash

cd Zion-2.9
docker-compose -f deployment/docker-compose.2.8.6-production.yml up -d
```

**Services Available:**
- **RPC Server:** `http://localhost:8545` (JSON-RPC)
- **Mining Pool:** `stratum+tcp://localhost:3333`
- **Pool API:** `http://localhost:8181/api/stats`
- **REST API:** `http://localhost:8001/health`
- **Grafana:** `http://localhost:3300`
- **Prometheus:** `http://localhost:9090`

### Option 2: Native Development

```bash
# Install dependencies
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Start blockchain node
python src/core/run_zion_node.py

# Start mining pool (new terminal)
python src/pool/pool_server.py

# Start miner
python zion_native_miner_v2_9.py --pool localhost:3333
```

### Option 3: SSH Server Management

```powershell
# Load helpers (Windows PowerShell)
. .\ssh-helpers.ps1

# Connect to server
zion

# Check status
zion-status

# View logs
zion-logs blockchain -Lines 100

# Restart service
zion-restart pool
```
