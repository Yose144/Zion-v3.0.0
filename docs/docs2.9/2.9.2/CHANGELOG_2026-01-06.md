```javascript
function parseJsonFormat(jsonStr) {
  const data = JSON.parse(jsonStr);
  
  // ✅ Handles presale format explicitly
  if (data.type === 'ZION_PRESALE_WALLET' && data.mnemonic) {
    return {
      type: 'import',
      mnemonic: data.mnemonic,
      address: data.address,
      tokens: data.tokens || 0,
      network: data.network || 'testnet',
      orderId: data.orderId
    };
  }
  
  return { type: 'json', data };
}
```

## 🎓 Technical Deep Dive

### Ed25519 Key Derivation:

```javascript
// From mnemonic to wallet
const mnemonic = "12 word phrase...";
const seed = await bip39.mnemonicToSeed(mnemonic); // 64 bytes

// Ed25519 uses first 32 bytes directly (no BIP32 path)
const privateKey = seed.slice(0, 32);
const publicKey = await ed25519.getPublicKeyAsync(privateKey);

// Custom Bech32 address
const address = customBech32Encode(publicKey); // zion1...
```

### Why No BIP32 Derivation?

**secp256k1 (Bitcoin)**:
```
seed → HDKey → derive("m/44'/0'/0'/0/0") → privateKey
```

**Ed25519 (ZION)**:
```
seed → privateKey (first 32 bytes)
```

**Reason**: Ed25519 má deterministickou strukturu klíčů. Pro single-chain wallet není potřeba složitá derivace.
