# README — Podklady k soudu (Návrh na změnu výživného)

Tato složka obsahuje připravené podklady pro soudní podání (návrh + přílohy).

**Poznámka:** Nejsem advokát a toto README není právní rada — je to pouze praktický „index a pořadač“ souborů, aby se v nich dalo rychle orientovat a snadno je zkompletovat k odevzdání.

---

## Cíl složky
- Mít na jednom místě:
  - samotný **návrh na změnu výživného**
  - související **přílohy** (exekuce, dluhy, ÚP, ocenění apod.)
  - poznámky / kontext (pro tebe) v [ZivotniReset.md](ZivotniReset.md)

---

## Doporučené pořadí pro kompletaci k odevzdání
1. **Návrh (podání)**
2. **Seznam příloh** (ideálně jako jedna stránka, kde je vypsáno „Příloha 1…N“)
3. **Přílohy** v pořadí, v jakém jsou uvedeny v seznamu

Tip: Pokud soud chce podání přes datovou schránku / ePodání, často se hodí mít buď:
- 1 PDF = návrh + všechny přílohy (sloučené), nebo
- samostatné PDF soubory, ale s jasným názvem a pořadím.

## Checklist před odevzdáním
- [ ] Je vybraný **jeden finální** soubor návrhu (PDF)?
- [ ] Sedí v návrhu: jméno, datum, podpis, soud, spisová značka (pokud je), adresy, účastníci?
- [ ] Je v návrhu jasně napsáno:
  - co přesně navrhuješ změnit (částka / periodicita)
  - od kdy navrhuješ změnu
  - stručný důvod (změna poměrů)
- [ ] Máš připravený **seznam příloh** a odpovídá reálným souborům?
- [ ] Přílohy mají čitelné názvy / pořadí (aby soudce nemusel hádat co je co)?
- [ ] Zkontrolované citlivé údaje (rodná čísla, čísla účtů):
  - pokud to jde, **začerni** nepodstatné části
  - nech viditelné to, co je relevantní
