## 2) Business Model pro Omnity.One s.r.o.

Firma **neprodává tokeny**. Prodává **software a služby**.

### 2.1 Produkty k prodeji

#### A) Software licence
- **ZION Miner Pro** - desktop/server mining software
  - Cena: 49-499 EUR / licence
  - Obsah: optimalizovaný miner, GUI, auto-update
  
- **ZION Pool Enterprise** - vlastní pool software
  - Cena: 1 999-9 999 EUR / licence
  - Obsah: full pool stack, support, customization

- **ZION Node Package** - full node + API
  - Cena: 299-2 999 EUR / licence
  - Obsah: blockchain node, API server, monitoring

#### B) SaaS služby (předplatné)
- **ZION Cloud Mining** - hosting mining operací
  - Cena: 29-299 EUR / měsíc
  - Obsah: managed mining, dashboards, payouts
  
- **ZION API Pro** - premium API přístup
  - Cena: 49-499 EUR / měsíc
  - Obsah: vyšší limity, priority support, webhooks

- **ZION DAO Toolkit** - governance nástroje
  - Cena: 99-999 EUR / měsíc
  - Obsah: voting system, proposal management

#### C) Hardware (volitelně)
- Předkonfigurované mining rig
- ZION branded hardware
- (dodavatel třetí strana, Omnity.One jako reseller)

### 2.2 Jak to funguje daňově

| Produkt | Daňový režim |
|---------|--------------|
| Software licence | Prodej nehmotného majetku, fakturace, DPH 21% |
| SaaS předplatné | Služba, fakturace, DPH 21% |
| Hardware | Prodej zboží, DPH 21% |

- **Žádné tokeny nejsou prodávány**
- **Zákazník si tokeny vytěží sám** (nebo je dostane jako mining reward)
- Firma má běžné příjmy z prodeje software/služeb

### 2.3 "Bonus" model (volitelný)

Zákazník kupující software může dostat jako **bonus/reward**:
- Early access k testnet
- Priority v mining poolu
- Governance hlasy (DAO)
- **Vytěžené tokeny z demo/test mining** (pozor: musí být skutečně vytěžené, ne přidělené)

## 3) Regulatorní srovnání

### Presale model (ZRUŠENO)
- MiCA Article 4-6: notifikace ČNB ✗
- AML zákon: registrace FAÚ ✗
- GDPR: plná KYC dokumentace ✗
- Daně: složitá struktura (zálohy, zásoby) ✗
- Právní náklady: 10 000+ EUR ✗

### Fair Launch + Software model
- MiCA: neaplikuje se (žádný prodej tokenů) ✓
- AML: neaplikuje se (žádné krypto transakce s klienty) ✓
- GDPR: standard (jen fakturační údaje) ✓
- Daně: běžný prodej software/služeb ✓
- Právní náklady: minimální ✓

## 5) Doporučený postup

### Ihned:
1. Zrušit presale plány a dokumentaci
2. Upravit whitepaper na fair launch
3. Připravit software produkty k prodeji
4. Spustit testnet/mainnet s open mining

### Do 1 měsíce:
1. E-shop pro software licence (Stripe, běžná fakturace)
2. SaaS dashboard pro předplatné
3. Marketing zaměřený na software, ne na token

### Dlouhodobě:
1. Tokeny získávají hodnotu organicky (těžba, burzy)
2. Firma má stabilní příjmy z software
3. Žádné regulatorní starosti
