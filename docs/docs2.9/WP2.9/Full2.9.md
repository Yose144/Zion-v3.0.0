| Feature | Value |
|---------|-------|
| **Type** | CPU-optimized PoW |
| **Memory** | 2 GB scratchpad |
| **ASIC Resistance** | High (random code execution) |
| **GPU Efficiency** | ~50% of CPU |

**Why RandomX?**

1. **Fair Mining**: Anyone with a CPU can participate
2. **Proven Security**: Audited, used by Monero since 2019
3. **Energy Efficient**: Lower power than SHA-256
4. **Decentralization**: No ASIC manufacturer advantage

```

```

### RingCT (Confidential Transactions)

Transaction amounts are cryptographically hidden:

```
Before RingCT:
"Alice sends 100 ZION to Bob" → Visible on chain

With RingCT:
"Alice sends [encrypted] ZION to Bob"
├─ Validators can verify: Input ≥ Output + Fee
├─ Cannot see actual amounts

```

### PPLNS Payout System

The pool uses **Pay-Per-Last-N-Shares (PPLNS)** for fair distribution:

```python
def calculate_pplns_payout(block_reward, miner_shares, window_shares):
    """
    PPLNS distribution algorithm
    
    Args:
        block_reward: Total reward for the block
        miner_shares: Shares this miner contributed in window
        window_shares: Total shares in PPLNS window
    
    Returns:
        Miner's proportional payout
    """
    PPLNS_WINDOW = 100_000  # Last N shares
    POOL_FEE = 0.01  # 1%
    HUMANITARIAN_TITHE = 0.10  # 10%
    
    # Calculate net miner pool
    after_tithe = block_reward * (1 - HUMANITARIAN_TITHE)
    after_fee = after_tithe * (1 - POOL_FEE)
    
    # Proportional share
    miner_ratio = miner_shares / window_shares
    payout = after_fee * miner_ratio
    
    return payout
```

### Smart Contract Logic

```python
# Simplified tithe calculation (actual in src/core/)
def calculate_tithe(block_reward: float, current_year: int) -> dict:
    """Calculate humanitarian tithe based on escalation schedule."""
    
    tithe_rates = {
        (1, 5): 0.10,
        (6, 10): 0.12,
        (11, 15): 0.15,
        (16, 25): 0.18,
        (26, 35): 0.22,
        (36, 45): 0.25
    }
    
    rate = 0.10  # Default
    for (start, end), r in tithe_rates.items():
        if start <= current_year <= end:
            rate = r
            break
    
    tithe_amount = block_reward * rate
    
    return {
        "total_tithe": tithe_amount,
        "humanita": tithe_amount * 0.60,  # 60% for humans
        "hanuman": tithe_amount * 0.40,   # 40% for animals
    }
```
