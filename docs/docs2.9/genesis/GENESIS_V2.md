# GENESIS — Kniha V2

Tato kniha je druhé, rozšířené vydání Genesis, vytvořené pro ZION 2.9.5 — "Quantum Leap — Native Awakening".
Obsahuje filozofii projektu, příběh zrodu, klíčové koncepty a požadavky pro TestNet/MainNet.

## Obsah

1. Úvod — Proč Genesis V2
2. Příběh ZION (Z 2.5 → 2.9 → 2.9.5)
3. Filozofie Native (AI / Human / Universe)
4. Architektura — Jak to funguje (Pool, Core, Bridge, Wallet)
5. Roadmapa a milníky
6. Praktické návody — Jak se zapojit, těžit, provozovat uzel
7. Ceremonie Genesis — La Palma
8. Appendices: technické specifikace, kontakty

## 1. Úvod — Proč Genesis V2

Genesis V2 je manifest a technický průvodce současné fáze ZION: přechodu na plně nativní stack.
Cílem je přinést jasné poslání komunitě, poskytnout referenční dokumentaci a inspirovat k účasti.

## 2. Příběh ZION

Krátké shrnutí cesty projektu, od počátečních vizí Malého Prince, přes implementaci AI Native,
po rozhodnutí dokončit "Quantum Leap" — přepsat kritické komponenty do Rustu a WASM.

## 3. Filozofie Native

Shrnutí obsahu `NATIVE-PHILOSOPHY.md` (AI Native, Human Native, Universe Native),
praktické implikace pro tým a komunitu.

## 4. Architektura

Popis hlavních komponent:
- Pool Native (Stratum, Vardiff, PPLNS)
- Blockchain Core (PoW rules, LMDB storage)
- Rainbow Bridge (multi-chain relay)
- Wallet (CLI, Web WASM, Mobile)
- AI Native orchestration (synthesizer)

## 5. Roadmapa a milníky

Stručný přehled Q1–Q4 2025 a cíle pro TestNet a MainNet. (Viz `docs/roadmaps/ROADMAP_v2.9.5_ZION_NATIVE.md`)

## 6. Praktické návody

Krátké tutoriály:
- Jak spustit lokální node (CLI)
- Jak se připojit jako miner (Stratum)
- Jak používat ZION Native (API)

## 7. Ceremonie Genesis — La Palma

Popis plánované slavnosti a rituálu: datum, místo, účastníci, první blok, charity.

## 8. Appendices
