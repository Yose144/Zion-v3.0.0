## 2. GPU Kernely — CUDA / OpenCL / Metal

Nové soubory v `L1/native-libs/all/`:

| Soubor | Backend | Target |
|--------|---------|--------|
| `cosmic_harmony_v42.cu` | NVIDIA CUDA | sm_70+ (RTX/A-series) |
| `cosmic_harmony_v42.cl` | OpenCL | AMD RX series, Intel Arc |
| `cosmic_harmony_v42.metal` | Apple Metal 3 | M1–M5 + NPU hints (simdgroup_matrix → ANE/AMX) |

Všechny kernely implementují kompletní CHv4.2 6-fázový pipeline (Blake3 → AES scratchpad → Merkle → XOR → Argon-lite → Blake3 finalize).

### Metal speciální funkce
- `chv42_mine` — hlavní těžební kernel
- `chv42_bench_phase2` — throughput test
- `chv42_npu_mix` — INT8 MLP přes `simdgroup_matrix` (mapuje na Apple ANE/AMX matriční jednotky na M2+)

## 3. Python GPU Wrapper

**Soubor:** `APP&WEB/desktop-agent/resources/mining/cosmic_harmony_v42_gpu.py`

Unified Python GPU interface s auto-detekcí backendu:
```
Metal (Apple Silicon) → CUDA (NVIDIA) → OpenCL (AMD/Intel) → CPU fallback
```

- `CHv42GPU.mine(header, nonce_start, nonce_count, target_u32)` → `Optional[Tuple[int, bytes]]`
- `CHv42GPU.mine_continuous(get_job, submit_share, stop_event, stats_callback)` — mining loop
- `CHv42GPU.benchmark()` → float H/s
- Standalone CLI: `python cosmic_harmony_v42_gpu.py --pool HOST:PORT --wallet ADDR`

Kernely jsou uloženy přímo vedle scriptu v `resources/mining/`:
- `cosmic_harmony_v42.metal` — Metal shader
- `cosmic_harmony_v42.cl` — OpenCL kernel

## 4. Desktop Agent — One-Click CHv4.2 GPU Mining

### Architektura (správná integrace)

CHv4.2 je integrováno do **existujícího** mining flow — žádný paralelní systém:

```
algo-select (dropdown) → config.algorithm = 'cosmic_harmony_v4_2'
Start Mining (existující tlačítko) → startMining(config)
  → CHv4.2 fast-path → spawn cosmic_harmony_v42_gpu.py jako minerProcess
  → stdout/stderr → existující miner-output události → existující log panel
Stop (existující tlačítko) → stopMiningAsync() → kill minerProcess
```

### Změněné soubory

**`APP&WEB/desktop-agent/src/main.js`:**
- Globals: `chv42GpuProcess`, `chv42GpuStats` (záložní stav)
- `startMining()` — CHv4.2 fast-path před standardním flow:
  - Detekuje `config.algorithm === 'cosmic_harmony_v4_2'`
  - Spawne `cosmic_harmony_v42_gpu.py` jako `minerProcess`
  - Používá venv python, správnou cestu ke skriptu (packaged i dev mode)
  - Stdout/stderr jde do existujících `miner-output` eventů
  - `miner-started` / `miner-stopped` události jako normální miner
- Záložní IPC handlery: `start-chv42-gpu`, `stop-chv42-gpu`, `get-chv42-status`

**`APP&WEB/desktop-agent/src/preload.js`:**
- Exposed: `startChv42Gpu`, `stopChv42Gpu`, `getChv42Status`, `onChv42Output`, `onChv42Stopped`

**`APP&WEB/desktop-agent/src/ui/index.html`:**
- `algo-select` — nyní viditelný dropdown (byl `view-hidden`)
- Přidána option `⚡ CHv4.2 Merkabah GPU`
- Odstraněn separátní `chv42-panel` (byl zbytečný)

**`APP&WEB/desktop-agent/src/ui/renderer.js`:**
- `algo-select` change handler → `config.algorithm = algoSelect.value`
- `syncAlgoUi()` aktualizuje display chip i status text
- `config.algorithm` se ukládá při Save Settings (byl hardcoded `cosmic_harmony_v3`)
- Inicializace z persistovaného configu
