## Co je 2.9.7

2.9.7 je **poslední verze před Code Freeze**. Jejím výstupem není nová funkce, ale **garance**: každý P0 blocker je uzavřen, zdokumentován s důkazem, a L1 blockchain jádro je připraveno ke genezi mainnet bloků.

Po mergi 2.9.7 do `main`:
- `docs/mainnet/MAINNET_CONSTITUTION.md` dostane SHA-256 hash + status `FROZEN`
- `docs/2.9.7/CODE_FREEZE.md` podepíšeme jako release sign-off
- Git tag `v2.9.7-freeze` označí freeze commit

## Kanárský testovací plán (před freeze)

### Minimální testovací sada pro 2.9.7 sign-off

1. **Stabilita** — 72h bez restartu všech 3 nodů (Helsinki, Usa, Asia)
2. **Mining** — alespoň 1 nalezený blok na testnet poolu za 24h
3. **Double-spend** — `test_double_spend_block_level_rejected` projde v CI
4. **Alertmanager** — simulovaný výpadek `zion-core` → Telegram notifikace za < 30 s
5. **Bridge** — 1 testovací lock+mint přes Base Sepolia (`ZIONBridge: 0xa5a09b2C09...`)
6. **Dashboard** — `zionterranova.com/dashboard` zobrazuje live pool stats (ne core RPC data)
7. **1000-miner stress** — `tests/mock_stratum_server.py` simulace nebo reálný load test

## Pre-mainnet gate (sjednoceno)

Před fyzickým MainNet launch jsou stále povinné 3 bloky:

- CHv4 produkční upgrade path (activation policy + release hardening + E2E run)
- Revenue produkční aktivace (wallety, buyback limity, 72h canary payout run)
- Genesis/freeze artefakty (sign-off + hashy + manifesty)

Autoritativní seznam je veden v `docs/2.9.7/MAINNET_READINESS_UNIFIED.md`.
- [ ] CI build zelený (`cargo test`, `cargo clippy -- -D warnings`, Hardhat)
