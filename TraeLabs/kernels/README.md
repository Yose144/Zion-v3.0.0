# GPU Kernel Workspace

This is where we'll experiment with GPU implementations of our experimental algorithms!

## Structure

```
kernels/
├── opencl/   # OpenCL kernels (cross-platform)
├── cuda/    # CUDA kernels (NVIDIA)
└── metal/   # Metal kernels (Apple)
```
